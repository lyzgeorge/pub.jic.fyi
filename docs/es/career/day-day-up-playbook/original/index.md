# Guía de carrera Day Day Up en Acción - Edición Original

### Un manual orientado a la práctica, en formato de clase

*Compilado el 2026-09-23 a partir de 270 videos transcritos ([YouTube @MrJonathanCareer](https://www.youtube.com/@MrJonathanCareer), canales de Bilibili y Xiaohongshu; ~188,000 palabras habladas). Cada afirmación de este libro proviene de esas transcripciones; no se ha añadido nada ajeno al corpus.*

## Cómo usar este libro

1. **Lee cada capítulo como una clase.** Cada sección numerada avanza de un concepto → el razonamiento del coach (normalmente desde la perspectiva del entrevistador o del gerente) → un método paso a paso → un guion práctico citado de los videos → los errores que el coach advierte evitar.
2. **Haz el conjunto de ejercicios antes de avanzar.** Los ejercicios están pensados para *hacerse*, no solo leerse: escribe la respuesta, grábate, practica el role-play con un amigo, reescribe el antes/después. Las plantillas son los guiones del coach con espacios en blanco para tus datos.
3. **Usa las fichas de repaso para prepararte.** Cada capítulo termina con un resumen de una página de sus marcos, fórmulas y frases - imprímelas la noche antes de una entrevista o una reunión uno a uno.
4. **Ruta sugerida para la búsqueda de empleo:** Capítulos 1 → 2 → 3 → 4 → 5. **Una vez empleado:** 6 → 7 → 8, con el 9 como hilo conductor.

Cuando dos videos difieren (el consejo del coach evolucionó entre 2018 y 2026), el texto lo indica.
