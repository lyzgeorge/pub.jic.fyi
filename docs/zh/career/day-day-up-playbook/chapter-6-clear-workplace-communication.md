# 第六章 — 清晰的职场沟通

> **原文标题：** Chapter 6 — Clear Workplace Communication
>
> **来源：** 摘译自基于 Jonathan Lee 职业辅导视频整理的《The Day Day Up Career Playbook》精简版

以"让对方理解，并做出有效回应"为优化目标。简单的语言、明确的重点和具体的诉求，比精心雕琢的措辞更重要。

## 6.1 先确定要传达的信息，再打磨措辞

在发送一条重要信息之前，先回答这三个问题：

1. 对方需要知道什么？
2. 这件事对他们为什么重要？
3. 我希望他们做什么？

然后把最重要的信息放在最前面。保留必要的背景信息，删掉那些不会影响决策的铺垫内容。

**修改前：**

> 我们在第二周遇到了供应商的问题，然后数据迁移花的时间比预期长，QA 又发现了一些问题。时间线可能会推迟。

**修改后（改编自原始素材）：**

> 我们目前进度落后两周，上线日期存在风险。造成延误的原因是供应商的延迟。我们是维持原定日期并砍掉报表功能，还是推迟上线日期？

这就是教练所说的"剪刀法"：先说**最重要的事**，最后再说**我为什么要告诉你这件事**。

## 6.2 根据具体情境选择一种结构

| 情境 | 结构 |
|---|---|
| 简短的进展更新 | 核心信息 → 原因 → 需要的决策或行动。 |
| 提出建议 | 建议 → 支撑理由 → 预期结果。 |
| 复杂的决策 | 情境 → 复杂因素 → 问题 → 答案（SCQA）。 |
| 会议发言 | 结论 → 支撑要点 → 影响 → 诉求。 |
| 演示汇报 | 一个核心结论 → 三个支撑性的关键节点 → 证据。 |

不要在一段回答里把好几种结构叠加在一起。选择那个能让问题最容易被理解的最简单结构。

**建议表达示例：**

> 我的建议是优先做功能 A。基于 X 和 Y，这能让我们最快地改善指标 Z。

同时要准备好解释其中的取舍和不确定性。一条清晰的建议，并不意味着要隐藏实质性的风险。

制作幻灯片时，把结论直接放在标题里。"因为客户结构变化，利润率正在改善"比"第四季度分析"能传达更多信息。每一页幻灯片都应该只支撑一个观点。

## 6.3 对自己的建议保持自信，对证据保持精确

把观察、解读和建议区分开来。在给出明确方向的同时，也要清楚地展示重要的局限性。

> 这个样本量比较小，所以这更像是一个方向性的信号，而不是确定性的结论。它与上个季度的趋势是一致的。我建议[下一步行动]来验证这个结论是否成立。

在谈论别人的行为时，描述实际发生的事，而不是给对方贴标签：

| 避免这样说 | 改成这样说 |
|---|---|
| "你就是不注重细节。" | "每日更新缺失了，导致客户看不到状态。" |
| "这是错的。" | "这部分我的看法不一样，原因是……" |
| "你为什么要那样做？" | "能不能跟我说说你当时是怎么想的？" |

在不理解的时候主动请求澄清，而不是假装听懂了：

> 能否再说一遍？我想确保自己理解了您的需求。

## 6.4 把承诺说清楚

去掉不必要的道歉和模糊措辞，但不要因此去掉责任感，或掩盖真实存在的不确定性。

| 习惯性说法 | 更好的表达 |
|---|---|
| "不好意思打扰你了，能给我个进展更新吗？" | "[事项]有进展更新吗？" |
| "就是随口问问……" | "跟进一下[事项]的情况。" |
| "我会尽量明天完成。" | "我预计明天完成。如果情况有变化，我会在下班前告诉你。" |
| 在还没搞清楚问题之前就先道歉 | "我们先把发生了什么、需要改什么说清楚。" |

如果确实犯了错，就坦然承认，并说明将采取的纠正措施。这里的重点是不要"条件反射式"地为一切事情揽责，而不是要你避免说"抱歉"。

## 6.5 用你的语音表达方式让信息更容易被理解

有意识地调整三个方面：

- **语速：** 在讲重要推理或不熟悉的术语时放慢速度。在关键点之前稍作停顿。
- **音量：** 保证在会议室或通过麦克风都能被清楚听到，同时不要刻意提高音量勉强自己。
- **语气：** 让自己的兴趣或关切自然流露出来。把陈述句真正当作陈述句来结束，而不是让每一条建议听起来都像是在提问。

在日常的沟通场合，把"参与进来"放在比"语法完美"更优先的位置。在高风险的沟通场合，提前准备好结构并大声练习。教练建议把简短的日常表达练习融入已有的日常习惯中；用它来建立表达上的自在感，而不是用来纠察每一个语法错误。

## 6.6 通过降低会议门槛来主动发言

你不需要每次都提出一个全新的想法。有三个实用的切入点：

1. **澄清：** "我们现在讨论的是哪个客户群体？"
2. **建立联系：** "这和我们上周看到的留存率问题有关吗？"
3. **推动落地：** "在我们能够继续推进之前，还需要先确定哪些事情？"

如果讨论进展得太快，可以先总结一下自己理解到的内容，再请求确认。如果是你在主持会议，就澄清会议的目的、把讨论拉回到需要决定的事情上，并在结束时明确责任人和下一步安排。

在闲聊场合，给对方一个小小的开口，并追问一个真诚的问题。重点是表现出真正的兴趣，而不是刻意展示一个令人印象深刻的人设。

## 6.7 把 AI 当作编辑，而不要因此丢失自己的表达

教练更推荐的做法是：内容由自己决定，用自己的语言把它写出来，然后再让 AI 帮忙润色。

> 修正语法并提升清晰度。保留我原本的意思、确定性程度和自然的语气。不要添加新的论点、泛泛的赞美，或额外的主张。

把修改后的结果大声读出来。把那些你自己实际不会说的措辞改回来，并确认修改没有改变你原本的承诺程度或确定性。工作相关的内容要使用公司批准的工具。

**发送或发言之前：** 核心信息容易被找到，证据能支撑这个信息，对方清楚需要做出什么回应，而且这些话听起来确实像是你自己会说的话。
