# 每天向上职场指南实战

*精简、可执行版*

本篇改编自基于 Jonathan Lee 职业辅导视频整理的英文原版精简教材（[The Day Day Up Career Playbook](https://www.youtube.com/@MrJonathanCareer)），侧重具体的决策、可执行的步骤，以及可复用的表达示例。相关建议主要基于教练在北美职场的视角，使用时请结合自己所在的岗位、雇主和所在地区进行调整。

**使用方式：** 求职阶段可重点阅读第一至五章，入职后的职场情境可阅读第六至八章。在评估自己的职业方向时，可参考第九章。直接跳到最相关的部分，把其中的步骤应用到自己面临的实际情况中，并用每章结尾的标准来检验结果。

**关于翻译与来源的说明：** 本篇是对英文精简版内容的编译整理，而非逐字翻译或经过逐条核实的教材，翻译时力求"信、达、雅"——忠实于原意、表达通顺、行文自然。示例和脚本经过改编或精简，除非特别说明。行动清单和限定说明中包含编者的判断。只使用真正适用于你自己情况的事实、成就和承诺。

**想读完整的原版教材？** 参见[原版全文](./original/index.md)，包含逐章的详细脚本、练习与速记卡。

## 目录

- [第一章 — 简历与求职材料](./chapter-1-resume-application-materials.md) — 写出体现影响力的简历条目、弥补经验空白，以及通过四条渠道触达招聘方。
- [第二章 — 面试准备](./chapter-2-interview-preparation.md) — 把岗位描述转化为准备简报，建立一个精简的故事库，并根据可用时间安排优先级。
- [第三章 — 回答面试问题](./chapter-3-answering-interview-questions.md) — 按问题类型选择回答结构，用 HEALER 框架讲好故事，并处理弱点与经验缺失类问题。
- [第四章 — 面试互动与后续跟进](./chapter-4-interview-dynamics-follow-up.md) — 根据面试轮次调整策略，提出能揭示真实情况的问题，并用具体内容做好后续跟进。
- [第五章 — Offer、薪资与职业决策](./chapter-5-offers-salary-career-decisions.md) — 在接受之前进行谈判、通读整份offer，并根据自己的优先事项比较不同选择。
- [第六章 — 清晰的职场沟通](./chapter-6-clear-workplace-communication.md) — 用"剪刀法"确定信息重点，选择合适的表达结构，并把承诺说清楚。
- [第七章 — 管理你的上级](./chapter-7-managing-your-boss.md) — 把一对一沟通变成对齐会议，尽早升级风险，并为绩效评估保留证据记录。
- [第八章 — 影响力、冲突与晋升](./chapter-8-influence-conflict-promotion.md) — 让有价值的工作被看见，用 ACT 框架推动方案落地，并把晋升变成一次具体的讨论。
- [第九章 — 职业策略与心态](./chapter-9-career-strategy-mindset.md) — 权衡回报与代价，从证据中建立信心，并区分技能、环境与市场问题。
