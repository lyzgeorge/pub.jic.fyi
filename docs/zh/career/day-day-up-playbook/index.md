# 每天向上职场指南实战

*精简、可执行版*

本书改编自基于 Jonathan Lee 职业辅导视频整理的英文原版精简教材（[The Day Day Up Career Playbook](https://www.youtube.com/@MrJonathanCareer)）。本指南侧重具体决策、可执行步骤及可复用的表达示例。职场建议主要基于北美环境，使用时请结合自己的岗位、雇主和地区调整。

**使用方式：** 求职阶段可重点阅读第一至五章，入职后的职场情境可阅读第六至八章。评估职业方向时可参考第九章。直接跳到最相关的部分，把步骤应用到实际情况中，并用每章结尾的标准检验结果。

**关于翻译与来源的说明：** 本篇是对英文精简版内容的编译整理，而非逐字翻译或经过逐条核实的教材，翻译时力求"信、达、雅"--忠实于原意、表达通顺、行文自然。示例和脚本经过改编或精简，除非特别说明。行动清单和限定说明中包含编者的判断。只使用真正适用于你自己情况的事实、成就和承诺。
