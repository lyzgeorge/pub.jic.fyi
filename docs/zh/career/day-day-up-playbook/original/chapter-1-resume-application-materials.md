# 第一章 — 简历与求职材料

> **原文标题：** Chapter 1 — Resume & Application Materials
> **来源：** 本文为《每天向上职场指南实战》原版全文（英文完整讲义版）章节的中文译本。

> 本章讲的是面试官开口之前发生的一切：简历、领英资料与筛选器、要不要投递的决定，以及能让真人看你一眼的主动出击。教练的核心论断是：大多数在北美求职的华人和非母语候选人，在这一步就出局了，而原因和能力毫无关系。他们把简历写成职责说明（"我和干过这份工作的所有人一样——没什么好看的"），留下了会让招聘者暗自怀疑其匹配度的细节，在HR拒绝他们之前就先自我否决，并且把100%的精力都投入在竞争最激烈的单一渠道——在线投递上。解决办法是把简历当作一份销售文件，把求职本身当作一个有四条渠道的系统，而不是只有一条路。

**读完本章你将能够**

- 用"技能 → 行动 → 结果"（问题 → 技能 → 成就）公式，把任何一条职责描述改写成有影响力的故事，并让每一行都通过"老板测试"。
- 按照教练的模板顺序，排出一页、单栏、ATS友好的简历，用一句话候选人陈述取代传统的个人简介。
- 剔除会让西方招聘者犹豫的红旗信号：公司所在地、仅限中国使用的工具、陈旧或不相关的工作经历、毕业年份，以及缺失的关键词。
- 在毫无相关经验的情况下，用免费的企业品牌模拟项目和自由职业经历"制造"出可信的经验。
- 像招聘经理写JD时那样去读JD——顺序即优先级，朴素直白的措辞异常之处才是真正的痛点——并在大致匹配三分之一要求时就投递。
- 使用领英筛选器、URL"秒级技巧"、Open-to-Work状态刷新，以及"hiring"帖子搜索，让自己进入前十名申请者之列。
- 用"二十法则"在"核心四象限"渠道之间重新分配精力，向决策者发送三段式冷启动私信，并让被拒绝的机会保持"温度"，留给下一次机会。

## 1.1 简历是什么：一份用六秒钟读完的销售文件

**核心概念。** 教练几乎在每一期关于简历的视频里都会回到同一句话：简历"不是一份法律文件，而是一份销售文件"。它不是历史教科书，不是护照，也没有人会去审计它。它唯一的任务，是让一个人做出"我们需要聊聊"的决定。

**读者的视角。** 关于阅读者的两个事实，决定了本章其余的一切：

1. **他们在寻找拒绝你的理由。** 筛选者内心真正的问题是"有没有理由不应该面试这个人？"。简历上的每一行，要么帮你在这个问题上得到有利的答案，要么正好给了他们正在寻找的那个理由。
2. **他们只花大约六秒钟。** 招聘者平均每份简历只看大约六秒钟，所以这份文件必须能被快速扫视：一页纸、最佳亮点放在上三分之一、关键词加粗、留白不要被填满，让面试与否的决定"不用动脑子"。

教练还指出了华人候选人天然会遇到的一种偏见。西方招聘者对以事实和职责为基础的写作方式存在偏见，也往往会低估中国经验的价值。他的应对方式不是抱怨这一点，而是："歧视是人性的一部分。问题是……如何把它转化为对你有利的东西"。1.2 至 1.4 节就是实现这一点的工具箱。

**简历绝不能做的两件事。**

- *描述职责。* 每一个担任过这个职位的人都做过同样的事；一份职责清单会让你隐形，"不管你的动词多么华丽"。
- *撒谎。* 撒谎在应届生和缺乏相关经验的人中很常见，而且这种做法必然失败——因为面试官会先表示欣赏，然后追问你如何衡量结果、为什么选择这个方法、最难的部分是什么。你是在"试图欺骗一个比你更有经验的人"。对一个你确实取得的成果进行合理估算是可以的（见1.2节）；凭空编造一项成就则不可以。

> 🗣 **教练原话：** "别浪费他们的时间，否则他们可能干脆浪费掉你的简历。"

**常见错误**

- 把简历当作一份完整履历，列出大学毕业以来的每一份工作。
- 为了填满空白而缩小字号塞入更多内容。
- 为自己而写（"我很努力"），而不是为筛选者而写（"这就是为什么有我在，这门生意会变得更好"）。

## 1.2 要点：三个层级、老板测试与黄金公式

**核心概念。** 简历上杠杆最高的单一修改，就是每一条要点（bullet）。教练把要点写作分成三个层级，而只有第三层级能带来面试机会：

| 层级 | 呈现方式 | 读者听到的信息 |
|---|---|---|
| L1 职责型 | "执行月末对账，以核实财务记录的准确性。" | "和所有担任过这个职位的人一样。" |
| L2 量化型 | 每一行都塞满了数字。 | "编造的数字，我永远没法核实。" |
| L3 影响型 | 业务问题、你做了什么、给业务带来了什么改变。 | "这个人明白这份工作为什么重要。" |

注意L2层级的陷阱：教练*并不*反对使用数字——恰恰相反，他坚持要用——但没有业务故事支撑的数字，读起来就是无法核实的注水。"努力是廉价的，但对HR来说，真正重要的是影响力"。

**老板测试。** 要从一条职责描述中挖掘出隐藏的影响力，就问自己：*如果我把这项职责做到极致，我的经理为什么会高兴？* 答案不能是"因为我把它做完了"，而必须与业务相关。教练常举的例子是一位说"我只是做对账"的会计候选人。他问她："如果你的月末结账晚了两天会怎样？"——她这才意识到，真正的影响是：公司业务在增长，却不需要多招会计。

**黄金公式。** 多期视频用略有不同的说法给出了同一个三段式结构——技能+行动+结果；解决的问题+使用的技能+对业务的影响；问题 → 技能 → 成就；"你面对了什么挑战、用了什么相关技能、这对团队或业务有什么帮助"。综合起来的方法是：

1. **以业务问题开头**（客户投诉、结账延迟、业务量激增）——这正是老板测试要挖出来的东西。
2. **点出你使用的技能或工具**——并且措辞尽量借用目标JD中的原词（见1.5节），这样也能匹配ATS系统。
3. **陈述结果**，归为以下三类影响之一：收入提升、成本下降，或效率提高。
4. **控制在两行以内。** "三行读起来很累，而一行又没有足够的细节"。

**来自原始素材的改写示例。**

```
改写前  执行月末对账，以核实财务记录的准确性与完整性。
改写后  重新设计对账流程，以解决交易量增长带来的月末结账延迟问题。
        将结账时间缩短两天，支持公司在不增加人手的情况下实现快速增长。
```


```
改写前  使用 Python 清理数据管道，将报告耗时缩短40%。
改写后  主动解决客户对报告流程的投诉，构建了基于 Python 的自动化
        数据清理管道，将人工报告耗时缩短40%。
```
注意"改写前"其实已经带了一个数字——这属于L2层级。真正让它跃升到L3的，是把"客户投诉"放在了最前面。

```
改写前  我把数据录入客户数据库的电子表格中。
改写后  管理客户数据库，日均录入超过500条数据，并主动
        将25%的常见录入项自动化，以提升个人与团队效率。
```
同一条要点后来又出现为："管理超过500条日常录入数据，主动使用RPA将25%的任务自动化，并带动了整个组织范围的自动化推广"。教练在这里指出的模式是：规模（每日数字）→ 主动采取的行动 → 提升的百分比 → 谁从中受益。

**关于你没有的数字。** 大胆估算。"没有人会去核实你到底是把效率提升了20%还是2%"；也没有人会打电话给你的前经理去核实21%和22%的区别；"没有人在审计你"。数字的意义在于证明你理解并能衡量价值。"我从没遇到过一个真的无法通过一点创造性思维量化出来的成就"。

> 🗣 **教练原话：** "一份好简历最重要的一件事，就是展示因为有你在，发生了什么改变。"

**常见错误**

- 给一条职责套上华丽的动词（"牵头数据录入项目以改善业务成果"）——本质仍是L1。
- 每一行都有数字，但没有陈述问题——读起来像编造。
- 用"因为我把它做完了"来回答老板测试。
- 写成三行的要点。

## 1.3 结构与排版：模板、一句话陈述，以及ATS友好的排版

**核心概念。** "好的排版不会让你被录用，但差的排版会让你被拒绝。" 教练分享了一个模板，他表示自己拿到谷歌、优步、宝洁和Shopify的offer都用的是这个模板，也是他的候选人中表现最好的模板。

**章节顺序**
1. **姓名** ——如果你对使用英文名还是中文名没有特别偏好，用英文名："会因此歧视你的招聘者很少见，但确实存在。"
2. **简介** ——除非你确实有值得一提的内容，否则跳过；最多写一行，用来概括你独特的核心竞争力，并引发读者的好奇心。
3. **工作经历** ——至少占简历的一半篇幅；按时间顺序排列；每份工作2到5条要点；每条要点两行。
4. **其他相关经历** ——较早或不太相关的工作，保持简短，"主要是为了让时间线说得通"。
5. **教育背景** ——如果你是应届毕业生或仍在校，放在最上面；否则"往下放，往下放，再往下放"。
6. **技能 / 资格证书** ——从目标JD中提取的硬技能，加上所需的资格证书。
7. **兴趣爱好** ——可选，用来增添一点个人色彩。

**一句话候选人陈述。** 塞满"学习能力强、充满活力的专业人士、领导者"这类字眼的多行简介，只会拖累你；你的整份简历本身*就是*你的简介。页面顶部是黄金地段，所以要用一句话代替整段文字，这句话要确认你的方向、经验和技能，并且能在30秒内重新调整以适配不同岗位。唯一的例外，是一句真正引人注目的话——教练举的例子是一位奥运金牌得主转型做战略咨询。

```
[数据驱动的] [职位] ，拥有 [N年] 经验，善于运用 [技能]
在 [行业] 中推动 [影响]。

"数据驱动的业务分析师，拥有五年经验，擅长运用数据叙事
 在快消品行业推动业务影响。"
```


**项目经历 vs. 工作经历。** 一位有三年经验的数据分析师找到教练时，简历里的项目部分比工作经历部分还长。这种比例传递出的信号，是对自己真实经验缺乏信心；项目是"玩具，而不是生产级资产"——没有截止日期，没有业务需求，数据也是完美的。要让项目部分比工作经历部分更短。（唯一的例外，是你完全没有工作经历——见1.4节关于如何"制造"经验。）

**排版规则**（综合整理）：

- 传统单栏、黑白配色。设计感强的模板会"杀死ATS"；每个部分必须既能被人读懂，也能被机器解析。
- 一页纸，除非你有10年以上经验，或需要提交CV形式的文件。
- 字号：Bilibili视频中说10pt或更大；更早的YouTube视频则说完全不要用10号字，也不要填满留白。把两者结合来理解就是："10pt是底线，如果你已经在这条底线上，说明你的内容太多了。"
- 最佳亮点放在上三分之一；关键词加粗。
- 文件名本身也是第一印象的一部分。

> 🗣 **教练原话：** "哦，等等，这才是你简历该有的样子。" ——谈到"资格摘要"这一部分时说的。

**常见错误**

- 使用ATS无法解析的双栏或图形化模板。
- 项目部分比工作经历更重。
- 一个已经毕业十年的人，还把教育背景放在最上面。
- 把简历命名为"resume_final_v3.pdf"这种文件名。

## 1.4 排除红旗信号：为移民简历降低风险，并填补经验空白

**核心概念。** 即使是包容度很高的招聘者，心里也可能有个小声音在说："他们来自另一个国家，英语是第二语言，他们能融入吗？" 你的任务，就是消除一切会触发这个声音的因素，让读者把注意力放在经验本身，而不是出身背景上。"不要只是翻译你的经历，要翻译它所讲述的那个故事"。

### 四项删减

综合整理如下：

1. **公司所在地。** 只列出中国公司的名称，如果有官方英文名就用官方英文名。"你的简历不是护照。"
2. **非全球通用的工具与流程。** 替换为西方对应物：小红书 / 抖音 → Instagram / TikTok；钉钉 → Slack 或 MS Teams。如果觉得这样做像是在撒谎，那就去学一门对应工具的课程。"招聘经理在意的是能否认出这个工具，而不是翻译得对不对。"
3. **陈旧或不相关的工作经历。** 把所有经历都列出来，会让你显得没有方向或"资历过高"——而"资历过高"常常只是"年龄歧视的委婉说法"，是"穿着西装的年龄歧视"。教练举的例子是：一位加拿大会计师在中国有五年新闻从业经历、五年财务经历，被完全从简历上删除，让简历聚焦在近期的加拿大经验上，结果这份简历"像是完全变成了另一个人"。
4. **毕业年份。** 西方简历不要求写毕业年份；一个十年前拿到的机器学习学位，会让人不由自主地拿你和今年的应届生比较，而这种比较对你毫无益处。

### 缺失的技能："即时补课"

如果JD要求某项技能而你没有，又选择不写在简历上，ATS的关键词匹配就会失败，人力资源可能根本看不到这份简历。教练的规则是：先把这项技能写上简历，然后去学——一个周末的Python课程就是他常举的标准例子——但绝不能声称自己已经精通，并且如果有技术面试环节，要提前做好充分准备。"你不需要谁的许可才能声称自己具备基本熟练程度"。"速度就是生存"。

### 没有相关经验：自己创造经验

"你不可能一直有工作，但你永远可以在努力争取"。你可以自己创造出三种经验来源：

- **企业品牌虚拟实习项目（Forage）。** 一个免费平台，提供由摩根大通、波士顿咨询集团（BCG）、百事、塔塔等公司设计的实操模拟项目；每个项目只需几个小时，能拿到证书，还能在简历上写上一个知名企业的名字。教练提到的两个AI相关例子是：BCG的生成式AI金融聊天机器人项目，以及塔塔的生成式AI数据分析项目。（教练说明自己并非因推荐而获得报酬；原始录音中该平台名称听起来像"theforge.com"。）
- **自由职业。** 在Upwork上，"哪怕只有一个客户、一个项目，也可以单独作为一段工作经历"。
- **发布到网上的个人项目**。

用和写工作要点相同的公式，把每一段经历写进"项目"部分：解决了什么问题、使用了什么关键技能、项目本身预期达成的成就。附带的好处是：知名品牌名会让快速浏览的招聘者停下来多看一眼，而对应的职位名称、技能和公司名也能提高你的ATS匹配度。相比堆砌关键词，一个有品牌背书的项目是在"用事实证明，而不是空口说"你对某个领域（比如AI）的兴趣。

### 无法删除的红旗信号

有些红旗信号是没办法从纸面上抹去的——短任期、职业空档期、从一家理想公司离职、在同一级别待了五年。教练在面试环节给出的建议是：面试官害怕两种候选人画像——*跳槽风险型*和*低绩效型*——而你应对的方式，是主动用一个故事去先发制人，而不是藏着掖着："没错，你的简历上有红旗信号。我桌上的每一份简历都有。你只管举起那面旗，然后向我证明，我没什么好害怕的"。这部分内容属于面试相关章节；本章关于简历的任务，只是先弄清楚你的简历会触发哪种担忧，好让你提前做好准备。

> 🗣 **教练原话：** "你会被两件事之一所限制：你的技能，或者你的信念。永远不要让限制你的是信念。"

**常见错误**

- 在每一家雇主后面都留着"北京"或"深圳"字样。
- 列出钉钉、小红书或其他西方读者不认识的工具。
- 在一页纸上塞进二十年的履历，读起来毫无重点，也显得资历过老。
- 等到找到一份工作之后，才去获取这份工作要求的经验。

## 1.5 读懂职位描述，决定是否投递

**核心概念。** 一份JD是"一份愿望清单，而不是一份checklist"。招聘经理往往照抄同类岗位要求写出不切实际的清单，结果所有人都在"追逐同一只独角兽"。教练自己招聘战略与运营岗位时写的JD，要求投行或咨询背景、5到7年经验、有团队管理和技术接触经验，但他最终录用的人只有大银行的五年经验，其余条件一条都不符合——"这是我能招到的最好的人"。

> 🗣 **教练原话：** "筛选候选人是HR的工作，不是你的工作。"

### 判断是否投递的三条规则

1. **三分之一法则。** 如果你满足大约三分之一的要求，就投递。那三分之一，可能正是经理真正在意的部分。
2. **要么匹配职位名称，要么匹配行业，不要两个都换。** 一位在银行业工作的会计，可以转到科技行业做会计，也可以转到银行业做FP&A经理；但要跳到科技行业做FP&A经理，就是双重跳跃，难度大得多。教练在自己从传统企业转向科技行业时也遵循了这条规则：保留"战略与运营"这个头衔，只换行业。
3. **顺序就是优先级。** 要求清单中最前面的几条，是经理最在意的；越往后的条目，可谈的余地越大。

### 像招聘经理写JD那样去读JD

教练建议把一份JD读两遍：投递前读一遍，面试前再读一遍。投递前这一遍，要找两样东西：

- **顺序。** "排在最前面的，就是招聘经理最在意的。"
- **异常之处。** HR总是把JD往"复杂的公司套话"方向修饰——在教练自己的案例里，"能在没人手把手帮忙的情况下，对副总裁说不"被改写成了"较强的沟通能力"。任何一句朴素、不寻常、不像公司套话的句子，往往是经理坚持保留下来的真实需求。那一句话，正是你要量身定制去回应的痛点。

决策者"不是一套ATS系统，而是一个正身处困境的真实的人"。所以要针对这份痛点去调整简历，而不是简单地堆砌关键词——但仍然要为最优先的几项要求和那处"异常之处"加入关键词，因为ATS会先运行筛选。这也呼应了教练更早给出的建议：一次认真的投递，意味着大约花十个小时研究这份JD、和做这份工作的人聊一聊，并把故事改写得高度聚焦于这些技能，这样简历才能既通过自动筛选，又能在到达真人手上后读起来令人信服。

面试前的这一遍阅读，则要把JD拆分成"你能否胜任？"的信号（日常工作、核心职责、前任的项目内容）和"我愿不愿意和你共事？"的信号（诸如"思维方式与众不同""在混乱中也能游刃有余"这类特质词）——后半部分的内容会在面试相关章节展开。

> 🗣 **教练原话：** "大多数候选人读JD是为了决定要不要投递。而那些真正被录用的人，读JD是为了决定自己要成为什么样的人。"

**常见错误**

- 因为十条要求里只满足六条，就自己先放弃了。
- 一次性同时更换职位名称和行业。
- 把JD里的每一条要求都当作同等重要。
- 只顾着为ATS堆砌关键词，却忘了背后还有一个真人在读。

## 1.6 投递：时机、领英筛选器与每日系统

**核心概念。** "问题不在于你，而在于你的筛选方式。" 一百个投递者里能拿到面试的只有百分之一；十个里只有一个也就是十分之一。教练这个洞察来自招聘方的经验：当他管理团队时，无法招到足够多*合格*的应聘者，只能亲自在领英上寻找候选人，也亲眼见过招聘者是按滚动方式筛选的——一旦一周的五个面试名额被填满，之后再投递的申请就根本不会被看到。

### 三个领英小技巧

1. **尽早、尽快地筛选。**
   - 把职位筛选器设置为**"申请人数少于10人"**。
   - 把**"发布日期"**设置为过去24小时，然后打开浏览器URL，找到参数 `r86400`（也就是24小时对应的秒数），把它改成 `3600` 表示过去一小时，或 `7200` 表示过去两小时。把这个技巧和"申请人数少于10人"结合使用，你就能"抢在最前面"。要立刻投递。
2. **刷新你的Open-to-Work状态。** 招聘者（以及教练自己在寻找候选人时）会筛选*最近*才设置为求职中的候选人，因为长期挂着"求职中"标签的个人主页，往往属于那些其实已经有工作、对外联系也不太回应的人。在周末开始时关闭这个状态，再在周末结束时重新打开，来刷新你的排名。
3. **搜索帖子，而不只是职位。** 招聘经理会自己发帖招人。搜索关键词"hiring"加上你的目标职位名称，然后把筛选器从"职位"切换到"帖子"。在那条帖子下评论或私信的合格人选，会被看到，而不是淹没在ATS系统里。（教练提供了一份用于此场景的冷启动私信模板；原始录音里没有完整读出，可以参考1.7节中的三段式私信模板来使用。）

### 把求职本身当作一个系统

教练把求职这件事本身也定义成一份工作。人人都想要大厂的offer，但很少有人愿意为此付出1000次投递、999次拒绝的代价。成功的候选人"靠的是流程，而不是一时的干劲"：一份用心打磨的简历、即使一直被拒也坚持每天投递、在收到面试邀约之前就持续打磨技能、把模拟面试当作反馈循环，还有一个能根据自己"投递转面试"转化率来设定每日投递目标的追踪表。"没有系统支撑的自律，其实就是在白白受苦"。

他也毫不客气地指出华人身上常见的一种反射性反应：遇到问题倾向于去学习，而不是去投递——"我们学习，是为了逃避真正去做"。2020年在优步工作期间，他刚新婚、背负着房贷压力，去上了一门自己很讨厌的Python课程，后来才意识到自己根本不想成为数据科学家；正是投递本身，而不是学习本身，让他明白没有人能像他那样讲故事。即使一轮投递以失败告终，也是值得的，因为它能揭示市场真正想要什么，以及哪些差距是真实存在的。

> 🗣 **教练原话：** "别再往脑子里塞更多的学习内容了。把内容塞进你的简历里才对。"

给代表性不足群体候选人的一点提醒：北美公司会设定自愿性的多元化目标，并主动在领英上寻找候选人——教练亲眼见过一位工程副总裁要求团队"至少主动联系三位来自代表性不足背景的候选人"。这里没有配额，也没有法律强制要求；你仍然需要是最合适的人选。但"要带着自信去求职，因为你值得，而且他们心里也清楚这一点"。

**常见错误**

- 投递一个已经显示100+申请人的职位。
- 把Open-to-Work状态开着几个月都不刷新。
- 只搜索"职位"标签页。
- 多报一门课，而不是多投五份简历。

## 1.7 超越投递本身：核心四象限、冷启动私信、内推，以及为机会保温

**核心概念。** 把求职想象成一个2×2的矩阵：认识你的人 vs. 不认识你的人，一对一沟通 vs. 一对多沟通。这样就得到四个象限——教练称之为"核心四象限"——而大多数人都困在最难的那一格里。

| | 一对一 | 一对多 |
|---|---|---|
| **他们不认识你** | 向决策者发送冷启动私信——"几乎没人这么做" | 在线投递——数以千计的竞争者 |
| **他们认识你** | 人脉 / 内推——有效，但正变得越来越饱和 | 在领英上分享专业见解——"公开学习" |

### 象限一：内推——真正的内推是什么样的

"一次真正的内推，不是某个员工帮你填一张表格。它发生在这样的时刻：那位员工亲口告诉招聘经理，我认识这个人，你应该面试他，理由是XYZ"。教练自己进入谷歌的面试机会，就来自一位朋友的内推，他说这条路径在那些被投递简历淹没的知名企业里很常见——不管是直接认识的人、二度人脉，还是网络上认识的陌生人，都可以请求他们帮忙说一句话。他也提醒，华人候选人常常默认求职就是"咖啡聊天加内推"，而西方职场的人际关系没有那么强的交易色彩；最有价值的联系人，往往是那些*真正做过这份工作的人*——比如招聘经理以前的直属下属，最好是干过同一个职位、如今已经离职的人。

### 象限二：冷启动私信——"猎鲸行动"

招聘网站信息滞后，还充斥着虚假、过期或不提供签证担保的岗位；按30天来算，"大多数公司光是回复你的投递，就要花上更长的时间"。所以要直接找到真正能帮上忙的人：总监、副总裁，甚至CEO。教练举出的结果包括：LVMH美洲区CEO给出的面试或offer（一位候选人在被拒绝*之后*给CEO发私信）、TikTok的一位副总裁，还有Sonos的CEO——"那最后一个就是我自己"。

30分钟流程：

1. 列出目标公司清单。
2. 找出每家公司的决策者——招聘经理、总监、副总裁、高管。
3. 发送一段简短的自我推介。

这段推介分为三部分：

```
1. 你的价值主张——你能为他们做什么。
2. 关于这家公司或这个职位的具体细节——证明你不是
   把同一条消息群发给了300个人。
3. 一个轻松、容易执行的行动号召——"我们聊聊吧。"
```

"这样做每次都能成功吗？当然不能。但它够精准、够快"。"我知道你能想出一百个不想去做这件事的理由。但去做就是了"。

### 象限三：公开学习

几乎没有华人职场人会做、但西方职场人常常在做的事：在领英上分享你的专业见解——比如，发一篇有深度的行业文章，配上你自己的观点，让你的人脉网络知道你懂什么。这对资深岗位尤其有用。教练曾合作过的一位总监，被裁员后连续一个月每天发帖，后来他说，正是这些帖子帮他拿到了一个副总裁职位。

### 二十法则

"每过二十天，如果你还没有得到想要的结果，就把20%的精力从投递简历这一项，转移到另一个象限里去。" 从100%投递开始，然后是80/20，接着60/20/20，再到40/20/20/20。顺序和具体比例反而不是最重要的，重要的是保持灵活。

### 让被拒绝的机会保持"温度"

被拒绝之后的沟通，本身也是一种求职素材。在24小时内回复每一封拒信，回复给一个真实的人——如果拒信来自一个无法回复的地址，就去找到招聘者或招聘经理的真实邮箱，或者在领英上加他们为好友。表达出简短的失落、感谢、持续的兴趣，并礼貌地询问能否日后保持联系。等到类似的职位再次开放时，不要悄悄地重新投递：直接在同一条邮件线程里回复。"在一堆简历中，这是最容易得到一句"好"的方式，因为对方上次已经喜欢你到愿意面试你"。教练说，有超过十个人写信告诉他，这封邮件"改变了他们的人生"，其中一人在被拒绝后不久，就在同一家公司拿到了offer。这两份话术模板都在"模板"部分。

> 🗣 **教练原话：** "人类雇佣的是他们信任、并且和自己有关系的人。"

**常见错误**

- 一连几个月把100%的精力都花在投递这一个象限上。
- 把提交一份内推表格误当作真正的内推。
- 给300个人发送同一条毫无具体内容的冷启动消息。
- 让一次拒绝彻底终结关系，之后又悄悄重新投递同一个团队。

## 练习题

### 训练

**D1 —— 老板测试审查（1.2）。** 复制你简历中最通用、最平淡的三条要点。在每条下面，用一句话回答：*如果我把这件事做到极致，我的经理为什么会高兴？* 如果你的答案里出现了"因为我把它做完了"或"因为做得很准确"，就再写一个答案，说明业务上究竟发生了什么改变（人手、结账时间、收入、投诉）。使用教练的提问方式："如果[这件事]晚了两天会怎样？"

**D2 —— 三次改写，每条两行（1.2）。** 把D1中的三条要点按"问题 → 技能 → 结果"改写。规则：业务问题作为第一个分句；工具或技能的措辞借用目标JD的原词；结果要体现为收入上升、成本下降或效率提升，并附上一个估算数字；严格控制在两行、字号10pt以上。对照对账和Python那两个示例检查你的改写。

**D3 —— 层级检测（1.2）。** 对你目前简历上的每一条要点，标注为L1（职责型）、L2（无故事支撑的数字型）或L3（影响型）。数一下各自的数量。如果超过三分之一是L1或L2，就安排时间重写它们。

**D4 —— 六秒扫视测试（1.1/1.3）。** 把简历给一位朋友看六秒钟，然后拿走，问他们记住了什么。如果答案不是你最想让人记住的那一点，就把那一点移到上三分之一，并把它的关键词加粗。

**D5 —— 替换简介（1.3）。** 删掉你的简介段落。写一行内容，格式为：*[修饰语] [职位]，拥有[N年]经验，善于运用[技能]，在[行业]中推动[影响]。* 然后在30秒内针对另一份不同的JD，再写出一个改写版本。

**D6 —— 格式检查清单（1.3）。** 逐项勾选：单栏 ☐ 黑白配色 ☐ 字号≥10pt ☐ 一页纸（除非10年以上经验）☐ 工作经历占页面一半以上 ☐ 项目部分比工作经历部分更短 ☐ 教育背景的位置符合时间远近 ☐ 技能来自目标JD ☐ 文件名专业规范 ☐。

**D7 —— 四项删减排查（1.4）。** 逐行检查，标出每一处公司所在地、每一个非全球通用的工具名称、每一份超出相关时间窗口的工作，以及教育经历中的每一个日期。对每个标记项：删除、改为官方英文公司名、替换为对应的西方工具，或移动到"其他相关经历"部分。

**D8 —— 即时补课的技能（1.4）。** 从一份目标JD中，列出你尚不具备的必需技能。本周就把最重要的一项加入你的技能部分，并预约一个能让这个声称变得真实的周末课程。记下哪些技能可能在技术面试中被考核，并提前做好准备。

**D9 —— 制造一段项目经历（1.4）。** 本周完成一个企业品牌虚拟实习项目。写一条两行的项目要点：解决的问题 → 使用的关键技能 → 项目本身预期达成的成就。对照目标JD的关键词检查这条要点。

**D10 —— JD分诊（1.5）。** 拿出一份你曾经放弃的JD。给其中的要求逐条编号，标出前三条。圈出任何一句用词朴素、不像公司套话的句子。数一数你满足了多少条要求——如果大约是三分之一，并且你匹配职位名称*或*行业，那本周就投递，并把圈出的那句话中的关键词放进你的第一条要点里。

**D11 —— 筛选器设置（1.6）。** 建立并保存两个领英搜索：（a）目标职位名称，申请人数少于10人，URL参数改为 `r3600`；（b）关键词"hiring [职位名称]"，筛选器设为"帖子"。每天检查这两个搜索一次。本周末，周五关闭Open-to-Work，周日重新打开。

**D12 —— 二十天日志与第一次"猎鲸"（1.7）。** 统计你过去20天的求职时间都投入在哪个象限。如果几乎100%都花在投递上却没有结果，那这周就转移20%的精力：列出五家目标公司，为每家找到一位决策者，发送五条三段式推介消息。

**D13 —— 拒信回复（1.7）。** 找出你最近收到的一封拒信。为它找一个真实的人类邮箱地址。发送下面的24小时回复模板（或稍晚一点发出）。设置提醒，持续关注该公司后续的职位空缺。

### 模板

**T1 —— 影响力要点**
```
[动词] [业务问题]，通过 [使用JD中出现的技能/工具的具体行动]，
[结果：收入 ↑ / 成本 ↓ / 效率 ↑，附估算数字]。
```

**T2 —— 一句话候选人陈述**
```
[修饰语] [职位]，拥有 [N年] 经验，善于运用 [技能]，
在 [行业] 中推动 [影响]。
```

**T3 —— 虚拟实习项目的项目要点**
```
[公司名] [项目名称] —— 使用 [关键技能] 解决了 [问题]；
达成了 [项目本身预期设定的成就]。
```

**T4 —— 给决策者的冷启动私信**
```
你好 [姓名]，
[价值主张——你能为他们做什么，一句话说清楚。]
[关于这家公司或这个职位的具体细节，证明这不是群发。]
[一个轻松的行动号召——比如"是否方便简短聊一聊？" / "我们聊聊吧。"]
```

**T5 —— 回复拒信（24小时内，发给真实的人）**

## 速记卡

**简历是什么：** 一份销售文件，不是法律文件，不是历史教科书，也不是护照。大约花6秒钟被读完，读者心里默默问："有没有理由不该面试这个人？"

**要点公式：** 业务问题 → 技能/行动（借用JD措辞）→ 结果（收入 ↑ / 成本 ↓ / 效率 ↑，附估算数字）。控制在两行。老板测试：*如果我把这件事做到极致，我的经理为什么会高兴？*——答案永远不能是"因为我把它做完了"。

**三个层级：** L1 职责型（隐形）· L2 无故事支撑的数字（无法核实）· L3 影响型（带来面试）。

**模板顺序：** 姓名（无所谓的话用英文名）→ 一句话陈述或不写 → 工作经历（占页面一半以上，每份2至5条要点）→ 其他相关经历（简短）→ 教育背景（只有近期毕业才放最上面）→ 来自目标JD的技能/证书 → 兴趣爱好（可选）。

**陈述句式：** *[修饰语] [职位]，拥有[N年]经验，善于运用[技能]，在[行业]中推动[影响]。*

**排版：** 单栏 · 黑白配色 · 字号≥10pt（如果卡在10pt说明内容太多了）· 经验不足约10年时控制在一页 · 关键词加粗，最佳亮点放上三分之一 · 文件名要专业规范。

**四项删减：** 公司所在地 · 非全球通用的工具（→ 换成西方对应物）· 陈旧/不相关的工作 · 毕业年份。

**经验空白：** 缺技能 → 写上去，本周末去学，绝不声称精通。缺经验 → Forage式的品牌项目 / 一个Upwork客户 / 个人副业项目，都按"问题 → 技能 → 成就"来写。

**何时投递：** 你满足约1/3的要求 · 只换职位或只换行业，不要同时换 · 你能对前三条要求以及那句朴素措辞的"异常之处"侃侃而谈。

**领英：** 申请人数少于10人 · 过去24小时内发布 → 把URL参数 `r86400` 改成 `3600` · 周五关闭Open-to-Work，周日重新打开 · 搜索"hiring [职位名称]" → 切换到"帖子"而不是"职位"。

**核心四象限：** 在线投递（最难的一格）· 内推（真正的内推 = 员工亲口告诉经理"面试他，理由是XYZ"）· 向决策者发冷启动私信（价值主张 + 具体细节 + "我们聊聊吧"）· 公开学习。**二十法则：** 每过20天没有结果，就把20%的精力从投递中移出。

**被拒绝之后：** 24小时内回复给一个真实的人；等新职位出现时，在同一条线程里重新联系。

**该做的：** 大胆估算数字 · 针对经理的痛点定制简历 · 在职位发布后的第一小时内投递 · 被拒绝后依然给CEO发私信。
**不该做的：** 罗列职责 · 编造成就 · 使用设计感强的模板 · 保留毕业以来的每一份工作 · 自我否决 · 用再报一门课来逃避行动。
