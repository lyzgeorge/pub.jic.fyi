# 第九章 — 职业策略与心态

> **原文标题：** Chapter 9 — Career Strategy & Mindset
> **来源：** 本文为《每天向上职场指南实战》原版全文（英文完整讲义版）章节的中文译本。

> 前面每一章讲的都是一项具体技能：一条简历条目、一个面试故事、一条给上级的消息。这一章讲的是这些技能背后的"操作系统"。教练在几十条视频中反复强调的核心观点是：在北美的华人和其他移民专业人士，很少真正受限于能力——"限制你的只有两件事：技能，或者信念。永远不要让信念成为那个限制"。这里说的信念是具体的、可以被识别并解除的：认为努力必然会被自动回报，认为要先有自信才能行动，认为一次挫折说明了你的价值，认为父母交给你的目标就是你自己的目标，认为安全的做法是等待。这一章里的大多数视频都以故事为主；本章提炼的是每个故事背后的推理和可迁移的方法，而不是复述故事本身。本章最后会讲到教练如何看待 AI 带来的变化——他认为，关键不在于学习 AI，而在于"发现你自己"。

**读完本章你将能够**

- 判断一个职业目标是否真正属于你，方法是问自己愿意为它承受什么，并把每一句"应该"的抱怨转化为可执行的"我怎样才能"。
- 把自信建立在证据而非情绪之上：先行动，重建"行动 → 习惯 → 性格"这条链条，并为失败做好设计，让风险不再感觉像生死攸关。
- 用第三人称重讲你最糟糕的职场经历，让它如实体现你的贡献，把挫折当作数据而不是身份标签。
- 按上行/下行的不对称性把风险分为"聪明"与"愚蠢"两类，只选值得冒的那些。
- 把自己的职业生涯当作一座花园来审视——种子、土壤、气候——判断该调整哪一层。
- 识别自己当前正被哪项职业 KPI 衡量（可靠性 → 主人翁精神 → 团队绩效 → 组织绩效），并通过回到市场来设定自己的晋升节奏。
- 用"留下来这件事，正在对我做什么？"来诊断一份糟糕的工作，并在 AI 时代把自己定位在知识库无法替代的地方。

## 9.1 这到底是谁的目标？主人翁精神、忍耐力，以及"应该"陷阱

### 概念

教练认为，很多职业上的痛苦并非来自一份辛苦的工作，而是来自追逐一个你从未真正选择过的目标。曾有观众留言说："没有人应该需要花这么多精力去迎合管理层，这太耗人了。"教练的解读是：这句抱怨表面上是在说精力，实际上是在说一种被困住、活得不真实的感觉。许多华人专业人士从小被父母和老师灌输了某种愿景，一旦达成就会被爱，久而久之，他们变得非常擅长揣摩别人想要什么——然后把这种能力称为"上进心"。

教练自己的版本是这样的：他父亲是多伦多一家餐馆的老板，曾指着市中心最高的那栋楼对他说："总有一天，你会买下那栋楼。"二十年后，他在 Uber 工作到凌晨两点，体重增加了三十磅，主导了 Uber 温哥华业务的上线，却什么感觉都没有。在一次飞机上，他对自己做了一次"五个为什么"的追问：我为什么要把自己逼成这样→为了升职→为了证明自己的价值→为了感到自己配得上→因为这是父亲的梦想。后来他从总监级别辞职，去做自己的事业——"不是别人大楼的顶层，是我自己的大楼"。

### 教练的推理

错误的问题是"我想要什么？"，因为"想要是廉价的"。每个人都想要升职、梦想中的 offer、大公司的履历——但很少有人想要为此付出一千次申请、九百九十九次拒绝。真正的问题是：

> 🗣 **教练原话：** "真正的问题是，你愿意为此忍受什么？"

一旦你诚实地回答了这个问题，两条路都是正当的。如果你真心想要升职——"是真心的想要，不是'我好像不得不要'"——那就接受其中的政治博弈、自我推销、对你不喜欢的人也要微笑点头，然后停止为此愤怒："这是你自己选的，承担它。"如果你不想要，那就按时打卡、把工作做好、按时回家，并有意识地选择这份安稳，"不带怨恨地看着别人升职"。怨恨的根源，恰恰是既想要回报，又拒绝承担代价。

一个相关的重新框定来自教练自己的心理治疗经历。想象一场 10 公里跑步，有人拿枪指着你的头逼你跑；在 Uber 的两年里，他就是这样跑的——凌晨两点的 Slack 消息、体重增加三十磅、一段几乎结束的感情、"在地铁上像僵尸一样失神"。这背后的信念是：工作是被强加给你的，而不是你自己选择的，"所以人们才需要被付钱才肯做"——这种信念被反工作、FIRE（提前退休）、"躺平"内容不断强化。而这把枪，最初是被爱意包裹着递过来的：父母（"你想要好生活吗？那你就必须好好学习"）、老师，然后是雇主。"没有人会告诉你，那把枪什么时候从他们手里，转移到了你自己手里。这个交接的时刻，我称之为成年。"教练明确表示，糟糕的管理者和有毒的企业文化是真实存在的结构性问题；但问题依然是——"这把枪，究竟握在他们手里，还是握在我自己手里？"他举了一个对比的例子：一位客户在中东竞争一个总经理职位，从早上七点工作到晚上十一点，却感觉很好，因为这份工作是他自己选择的。

> 🗣 **教练原话：** "当你意识到，根本没有人拿枪指着你的头时，终点线就不再是'生存'的模样，它开始变成'自由'的模样。"

### 方法：把"应该"换成"我怎样才能"

同一种主人翁精神转变的语言学版本，是教练在这个领域里最具操作性的工具。客户的抱怨——"我的经理应该多支持我"、"他们应该给我那个 offer"、"我应该获得那次升职"——都带着一种被亏待的感觉。"应该"这个词听起来很舒服，因为它把重量压在别人身上，但它"剥夺了你本该拥有的改变现状的力量"，而且它会欺骗大脑，让你误以为自己已经做了一切能做的事。他承认每一句抱怨可能都是真的——没错，好的经理应该支持你；没错，你确实是最合适的人选——然后他会说："职场从来不会是它'应该'成为的样子。"他自己的例子是：在帮公司挽回三千万美元损失、并带领二十人团队之后，他问："我觉得我已经准备好升职了，我们什么时候能推进这件事？"得到的回答却是："还没到时候，再等几年吧。"

1. **替换动词。**"我的经理应该多支持我" → "我怎样才能获得更多支持？""他们应该给我 offer" → "我怎样才能拿到这个 offer？""我应该获得那次升职" → "我怎样才能获得升职？"教练的观点是："你思考的方式塑造了你说话的方式，没错；但你说话的方式，同样也会塑造你思考的方式。"
2. **如果"我怎样才能"想不出答案，就把问题缩小成三个：**你想要感受到什么？什么能让你有这种感受？你实际能从哪里获得它？人们常常不知道自己想要什么，但他们知道自己想要什么样的感受。
3. **制定一个不止一条路径的行动计划。**一位客户觉得自己被一位为人和善但说话直接的经理忽视了。她发现自己真正想要的是感到"有能力"；一个更高的头衔能证明这一点；于是他们同时规划了一条内部调岗路径和一条外部申请路径。

同样的主人翁精神原则，也出现在教练那份快节奏的"真相清单"里：没有人像你自己一样在乎你的职业生涯；如果你不决定自己想要什么，你的经理就会替你决定；你经理的职责是管理你，不是培养你；没有人会给你工作生活的平衡，那是你自己创造出来的。在讲领导力习惯的那期视频里，这句话变成了："如果你不决定什么对你的成功而言是重要的，别人就会替你决定。"

### 常见错误

- 既想要回报，又对付出的代价心生怨恨——这正是"不带怨恨地看着别人升职"这句话反过来的来源。
- 把"应该"句式当作行动计划来陈述；那种"我是对的"的感觉，取代了真正去争取的努力。
- 把"我不得不"当成一种主动选择的"愿意"。教练的检验标准是*真心*的意愿，而不是无奈的妥协。
- 用忙碌来逃避。害怕的时候，华人的本能反应是去学更多东西——"我们学习，是为了逃避真正去做"；保持忙碌感觉比冒着被拒绝的风险更安全，但那其实是一种逃避。

## 9.2 自信是证据：先行动，再感受

### 概念

教练的立场很明确："自信不是起点，而是终点。"他带过大团队，做出过七位数的生意，也上过全国性电视节目——"这一切的过程中，我都怕得要命。"自我肯定式的口号和"假装自信直到真正自信"这类方法只是昙花一现："自我肯定和情绪都不长久，身份认同才会。"他的座右铭是"用证据战胜情绪"。在"2026年的经验教训"那期视频里，这被列为第二条："你之所以自信，是因为你行动"——他观察到，很多人把自己的职业生涯当作一场彩排，为了一个永远不会到来的"正式演出"时刻。

### 教练的推理

三个反复出现的机制：

**1. 恐惧是默认状态；让不行动比行动更痛苦。**人类天生对恐惧敏感。你无法靠"感觉勇敢"来让它安静下来，而是要让"不行动的痛苦，大于行动的痛苦"。教练举的是一个身体层面的例子：二十多岁时他体重超标，加班到凌晨两点吃麦当劳；后来抱侄女时闪了腰，这彻底打碎了他"我是运动型的人"这个自我形象。他开始"做健康的人会做的那些健康的事"，直到不去健身房比去健身房本身更让他难受。"你之所以缺乏自信，是因为你对自己的期望太高"——只要把小事做对，成功"就成了一种必然"。

**2. 结果由身份认同决定——重建这条链。**27岁时他体重220磅，靠速成节食两周瘦了10磅，两个月后全部反弹，因为"每一次健康的选择，都像一场几乎不可能通过的意志力考验"。真正改变他的那句话是："关注你的行动，它们会变成你的习惯；关注你的习惯，它们会变成你的性格；关注你的性格，它会变成你的命运。"他旧的链条是：凌晨两点吃一次麦当劳，"就这一次没关系"→ 一有压力就靠吃东西来安慰自己 → "一个不尊重自己身体的人" → 肥胖。33岁时他瘦了40磅，新的身份认同是："我是一个健康的人，而健康的人会照顾好自己的身体。"教练最核心的论断是："我们总想直接追求那个巨大的结果，却不愿先成为那个能够实现它的人。"

他把这套逻辑精确地对应到职场版本上。破碎的链条是：只有在有"值得说"的话时才开口（作为一个英语非母语者，这种时刻几乎从不出现）→ 习惯了沉默 → "一个没什么可说的人" → "会议室里的隐形人"。重建后的链条是：行动——"哪怕这个想法只是普普通通，我有想法就会说出来" → 习惯——习惯了主动发言 → 性格——"一个能给讨论带来价值的人" → 命运——在职场的任何场合都能好好地发出自己的声音。

**3. 为失败而设计，而不是为成功而设计。**"工作，是为了有一天可以说不干了；面试，是为了有资格失败。"人之所以会犹豫，是因为"你把成功当成了目标"，于是每一次冒险都"感觉像生死攸关"，失败也"威胁到了你的身份认同"——这正是为什么你在团队会议上早就练习好的那句话，最后还是没说出口。那些活得自在的人，"追求的是过程"。把每一次行动的目的重新定义：做一场演讲，是为了收集批评；主动申请一个项目，是为了观察自己在面对新挑战时的反应；一次面试，是为了"换来一次能精确告诉你哪里还能做得更好的拒绝"。"当你拥抱了最坏的结果，最坏的结果就不再可能发生了"，而每一次失败，都排除了一条通往真正目标的错误路径。

> 🗣 **教练原话：** "如果你的目标从来就不是成功呢？如果你想要的是，比在场任何人都更彻底地失败、更快地学到东西，你会怎么做？"

### 方法

1. **先决定你想成为什么样的人**（是身份认同，而不是结果）。
2. **选择那个身份会采取的最小的一个行动**——"哪怕想法只是普通，我有想法就会说"——不管感觉如何都去做："去他的，我就是要带着恐惧去做"。
3. **把每一次尝试的目标设定为收集反馈**——在演讲或面试之前，先写下你希望收集到的那些批评意见。
4. **记录证据。**自信是从记录中积累出来的，不是从心情里积累出来的。
5. **审查你的"账本"。**"你的账本从不撒谎"：教练曾经告诉自己，他是一个有创造力的创业者，而他的日历上写的却是凌晨两点在 Uber 做 Excel 报表，他的银行账户里记录的则是追涨杀跌带来的亏损。"你悄悄地被你的行动证明成了什么样的人，你就是什么样的人。"看看你的日历和银行流水，它们才真正显示出你是谁。

一个真实的教练案例：一位会计升任主管后，入职几周就陷入恐慌。教练给出的建议很简单："多做一点，你就会感觉好一点。"两年后，她成了顶尖绩效者，还经营着一份副业。另一个例子：教练自己曾多年回避做内容（"我不是那种适合做社交媒体的人"），尽管客户成果出色，却始终默默无闻；发布了一条视频后，两年内积累了超过十万粉丝。经验教训之三："技能是容易的，信念才是难的"——华人专业人士热衷于追逐学位和证书，却很少去质疑自己的信念。他常问自己的一句话是："是谁说我需要更多？"去申请，让经理说"不行"；说出那句话，让对方去回应。

### 关于等待

教练用了五年时间，在夜晚和周末搭建起自己的教练事业，一直在等待"合适的时机"离开一份他其实很喜欢的工作。2023年两次家人的医疗突发事件让他明白："生活不会等你。"内心那个要求"更多证据、更多认可、更多确定性……"的声音，"其实不是在帮我，它就是死亡本身"——死亡"不喧哗，它很安静，它看起来像舒适，像确定"。在"2026年的经验教训"那期视频里："等待到了某个节点，就不再是自律，而变成了恐惧。"他给出的反思问题是："如果什么都不改变，你会有什么感受？"——从未尝试那个想法，从未搬去那座城市，从未对那个人说出那句话。

### 冒名顶替综合征与镜子

教练把冒名顶替的感觉看作一个信号，而不是一个定论："冒名顶替综合征恰恰证明你已经上了一个新台阶。如果你是房间里最聪明的人，那说明你走错了房间。"对新员工，他会说："你觉得你的经理是傻子吗？不是？那你为什么会怀疑他雇你雇错了？""不要试图压制它，给它一个温暖的拥抱，感谢它的出现。"对移民专业人士，他的打气版本是：你不需要再拿一个学位，也不需要更流利的口语，"你需要的是一面镜子。"口音"意味着你胸口装着一段故事"；从零开始意味着"你现在知道该怎么从零建到一了。"值得记住的两句话："我经历过比这更难的事，我还站在这里。""让我给你看看我建成了什么。"

### 常见错误

- 等到"感觉准备好了"才行动。"职业生涯常常被当作一场彩排，为了一个永远不会到来的正式演出。"
- 试图靠意志力去实现一个巨大的结果，而不是从小行动开始改变；速成节食式的循环。
- 只有在有"值得说"的话时才开口——这是英语非母语者陷入隐形状态的陷阱。
- 依赖自我肯定的口号。"自我肯定和情绪都不长久，身份认同才会。"

## 9.3 重写你的故事：挫折是数据，成就是证据

### 概念

"我们习惯把失败归咎于自己，把成功归功于外部。"教练观察到，西方同事常常正好相反——成功是"他们自己的构想，自己的决定"；失败是"时机不对、流程问题、数据缺失"。两种说法都不算撒谎，因为：

> 🗣 **教练原话：** "每一个故事，都只是一堆事实的集合。如果你只挑选失败，把成功让给别人，你就得到了一个自我贬低的故事；反过来做，你就得到了一个自我肯定的故事。两个都是真的，那就告诉自己那个更好的版本。"

### 教练的推理

数自己的成就并不是自负，那是在"收集证据"，而证据正是自信、勇气和冒险精神的来源。"自我批判的故事不会让你变得更好，只会让你变得更害怕。"教练引用心理学家 Ethan Kross 的研究说，第三人称的技巧之所以有效，是因为用你自己的名字代替"我"，能阻止情绪的泛滥，让你能像"公正地评判一个朋友那样"来评判自己。

这种文化根源在那个关于 PIP（绩效改进计划）的故事里表现得最清楚。在 Uber 工作的第二年，新冠疫情刚开始时，他的经理因为沟通和表达能力问题，把他放进了一个绩效改进计划。他曾写过一封愤怒的邮件（"恕我直言，这纯属胡扯，你们只是想在不付遣散费的情况下裁员"），但最终只是把它存在了草稿箱里。他没办法告诉父母（他们的叙事是：聪明，但可能有点懒）或那些高绩效的朋友。他把这种羞耻感追溯到一种文化——"我的价值，活在别人的眼睛里"——面子、父母"在饭桌上给我打分"。这份羞耻一直跟着他：在下一份工作中，他为每一次三十分钟的一对一会议提前准备三十分钟，一位很和善的经理跟他说"你没什么需要证明的"，这句话却让他感觉很空洞。他的警告是：羞耻感"会让你付出代价——一次你从未开口要求的加薪，一次你从未去争取的升职"。当他为了开始自己的事业更新领英资料时，每一个个人主页都读起来像"一段充满毒性正能量的高光集锦"；他公开发布了那份 PIP 的经历，"那一天，我的羞耻感才真正消失了。"你不需要一次公开发帖，但你需要对自己诚实："当你知道自己是谁，你才有权决定这些数据对你意味着什么。"

> 🗣 **教练原话：** "一份 PIP，或者任何一次挫折，都只是数据。一次失败，也只是数据。"

### 方法：五分钟第三人称重写

1. 选择那件你最感到羞耻的职场经历。
2. 用第三人称把它写下来，就像它发生在别人身上一样。
3. 挑选那些最能体现这个人贡献的事实。
4. 反复讲述它，直到它成为你官方讲述的版本。

**实操案例——Eve 的仪表盘。**Eve 是一位没有工程背景的高级财务分析师，她害怕面试中被问到那个"失败"的实时销售仪表盘项目：CEO要求她来做，数据出了问题，她因此认定自己是"交付不出来"的人。教练用完全相同的事实做了重新框定：

> "公司里没有一个人能做出你们 CEO 想要的东西。所以在他所有员工中，他信任的是你——一位零工程背景的财务分析师。你自学了 Power BI，从零到一做出了公司的第一个仪表盘。数据出错，是因为公司本身没有数据基础设施——而你的仪表盘恰恰证明了这件事是可能做到的，并促成了公司正式招聘一名全职数据工程师。Eve，你并没有做失败这个仪表盘。你，正是这个仪表盘存在的原因。"

**自传版本。**教练用完全相同的三十三年事实，讲了两遍自己的人生。失败者版本：在一家餐馆家庭中贫穷长大，被欺负，又胖又书呆子气（外号"泡泡"），从未拿过第一，在职场中总觉得自己是冒牌货，创业屡屡失败，娶了第一个答应嫁给他的女孩。英雄版本，同样的事实：父母倾其所有；被划入"天才班"之后才开始被欺负；多伦多历史上最年轻的拼字比赛冠军，两次全国演讲比赛冠军；即便*身为 Shopify 的总监*，依然觉得自己是冒牌货；创业屡次失败，直到 Mr. Jonathan Office 成功；娶了他唯一开口求婚过的第一个女孩，携手十年。"作为华人长大，意味着我们选择为自己的人生写下失败者的那一面，指望它能激励我们"——"如果你其实一直都是那个英雄呢？"

### 决定你身价的挫折

有两期视频把同样的逻辑应用到金钱上。第一个是稀缺陷阱：一位求职者"M"面试连续失败二十多次，每次自我介绍开场都是"我最近刚被裁员"。他们重新设计了她的开场，改为以优势开头（"面试的全部意义，就是聚焦在你的优势上"），她拿到了 offer——然后立刻签了合同，把自己贱卖了。"如果你拿到了 offer，说明公司认为你是最优秀的候选人，而最优秀的候选人理应获得最好的薪酬。"被拒绝，意味着"你还没找到对的那个匹配"；"稀缺感会让你的眼界变小。"原则是："永远不要让稀缺感来定你的价格。"第二个是剥削陷阱：一位拥有常青藤硕士学位的候选人，在一家小公司拿着最低工资，还被老板贬低。教练的重新框定是："你的劳动力，只会廉价到你自己相信的那个程度";那些搞剥削的公司"会永远停留在小规模……如果你只付最低标准，你得到的也只是最低水平";而且"你的价格，确实反映了你的价值，把这当作动力，去要求你应得的东西。"她最终拿到了一份口头 offer，薪酬翻了一倍还多。对于代表性不足的候选人，教练补充说，北美公司设有自愿的多元化目标，并会主动寻找这类候选人——"带着自信去求职，因为你值得，而他们也知道你值得"——但这"不是免费通行证"：你仍然必须是最合适的那个人。

### 常见错误

- 用亏损开场。"你好，我是 M，我有五年经验，我最近刚被裁员。"
- 让一次评价定义你，而不是仅仅作为参考信息。
- 把自我批评和自我提升混为一谈——那只会"让你更害怕"，而不是让你变得更好。
- 为了讨人喜欢而保持谦虚："你参加的不是谦虚奥运会"——谦虚只会让你一直保持隐形。

## 9.4 承担对的风险：伸展 × 坚持，聪明的风险与愚蠢的风险

![有边界的职业尝试与无边界风险的对比：限制损失、积累经验并保留选择](/assets/career/day-day-up-playbook/chapter-9/02-comparison-bounded-career-risks.png)

### 概念

"工作越努力，赚得越多"是一个谎言：建筑工人、护士和出租车司机比谁都更卖力地干长时间的活，但他们并没有因此赚得更多。收入其实是"你能伸展多远，乘以你能坚持多久"。绩效评估的真相也说明了同样的道理："绩效跟你工作有多努力无关。努力只是一个投入项，而投入项本身并不重要"，以及"光靠努力工作不是答案；如果你无可替代，你反而无法被提拔"。

### 教练的推理

- **伸展（Stretch）** = 有依据的冒险：高曝光度但有风险的项目、为一个你还没准备好的职位去争取、进入一个还没人相信的行业。
- **坚持（Stay）** = 在"什么都不确定的迷雾"中撑下去；大多数人恰恰在突破发生前一刻转身放弃。

他举的例子是：据报道 Meta 曾以每年两亿美元的价格挖走一名苹果工程师加入其 AI 团队，而蒂姆·库克 2024 年的年薪是七千五百万美元。这位工程师并不是聪明两倍，他只是"在 AI 还没火起来之前就提早伸展，把整个职业生涯押在了 AI 上"，并且一直坚持打磨技能，"直到全世界都追上来"。

> 🗣 **教练原话：** "你下一次涨薪，不会来自又一个熬夜的晚上，而会来自那个你最害怕去冒的风险。"

**该冒哪些风险？**在动荡的时代——反移民情绪、签证政策一夜之间变化、中西方关系紧张、经济疲软、AI——问题不是"我应不应该冒险"，而是"哪些风险值得冒"。教练的两部分框架：

1. **控制你的视角。**我们从小被教育说，控制会让你更强大——规划好一切、把错误降到最低、加倍努力——但"你不是靠硬扛熬过艰难时期的，而是要学会顺势而流"。你无法控制经济，但你可以控制自己和金钱的关系（"我真的需要再买一个 Labubu 吗？"）；你无法控制签证政策，但你可以控制自己的准备程度和自我价值感，"它不该被护照上的任何一个章所定义"。他举的榜样是诗人苏轼，被贬谪、被嘲讽，他也会抱怨，但之后依然继续写作、继续作画——观察、接受、继续前行。
2. **控制你的反应：避免愚蠢的风险，寻找聪明的风险。**愚蠢的风险，是下行空间无限、上行空间有限的——比如在下跌行情中加杠杆买加密货币，或者借钱投进比特币想快速把亏损赚回来。聪明的风险，是下行空间有边界、上行空间没有上限的——比如构建"可迁移的价值"，一项全球都需求旺盛的技能；投资自己；上一门课；做一份小生意。最坏的情况，无非是每周损失几个小时或一小笔投资；最好的情况，则是你"在任何地方都势不可挡"。在不确定的时代，本能地回避一切风险是很自然的，但"大多数风险其实都提供了机会"。

> 🗣 **教练原话：** "我们跨过海洋、学会新的语言、从零开始重建人生。'顺势而流'早就流淌在我们的血液里……我不希望你只是'生存下来'，我希望你能'顺势而流'。"

### 句子层面的风险：汇报 → 建议 → 承诺

教练把敢于承担风险称为一项"高阶的职场技能"，并把它定位在你沟通的方式上。汇报（事实、洞察）是大多数华人专业人士所在的舒适区；建议是提出一个观点，但最终决定和执行仍由别人来做——"而风险恰恰就在这里……这几乎是你和你经理之间唯一的区别之一"。承诺，则是自己做出决定，并为之负责。晋升"从来不是奖励给永远正确的人";它们属于那些在没有明确答案时，依然愿意做出艰难决定的人。这句习惯用语是：

```
我看到的是 [某个洞察]。如果由我来做决定，我会 [某个决策]，因为 [某个理由]。
```


### 关系中的风险：正面交锋与冲突风格

素材中有两种框架。Shirley 是一位曾任高级数据科学家、现正学习心理治疗的嘉宾，她把"正面交锋"重新定义为"我的'正面'去迎接对方的'正面'"。她过去只有两种模式——戴上面具维持和平，或者一股脑倾泻丑陋的情绪——她之所以回避正面交锋，是因为她把它等同于第二种模式。她的重新框定是："每一次交锋，都是共同创造出来的"——你可以选择带哪一面自己出场，从而也邀请对方带出不同的一面来回应你。正面交锋因此变成了"让更多真实的自己向前迈出一步，看看对方是否也愿意在那里迎接你的冒险"。她举的例子，是她在一次疫情期间的视频通话中，从未问过一位产品负责人的一个私人问题——关于他家里的装饰品："我很喜欢你布置沙发的方式，你也对家居装饰感兴趣吗？"

教练自己对冲突的框定，拒绝了"更狠地怼回去"这种建议，因为它没有对事后的结果负责。先弄清楚你属于三种回应者中的哪一种——战斗型、逃跑型（离开或回避）、忽略型（承认对方说了什么，但依然按自己的想法去做）——然后选择那个你事后会为自己感到自豪的方式。他妻子是战斗型的人，走开时反而心满意足；他自己是忽略型的，也感觉挺好；两种都是合理的。英语版本还加上了"冻结型"（拖延，希望问题自己消失——这是他自己的默认模式）以及那个决定性的问题："哪条路，是我事后会尊重自己的？"直接的反馈之后，必须立刻跟上支持和一个具体的计划。

> 🗣 **教练原话：** "衡量你是否'赢了'一场冲突的标准，不在于你说了什么，而在于结束之后，你是否依然为自己感到骄傲。"

### 常见错误

- 又一次靠熬夜来解决问题，而不是去面对那个你真正害怕的风险。
- 采取赌博式的风险来快速挽回损失（下行空间无限）。
- 在不确定的时期回避一切风险，而实际上"大多数风险都提供着机会"。
- 在迷雾中，恰恰在突破前一刻转身返回。
- 一直停留在"汇报"这一层，因为"决定"这件事让人感觉太暴露自己。

## 9.5 花园模型：种子、土壤、气候

### 概念

"你的职业生涯是一座花园，不是一架梯子。"成长取决于三层——**种子**（你的技能与天性）、**土壤**（公司、经理、同事）、**气候**（行业、地域、时机）——你必须照料每一层。教练把这称为普通人职业跃升的"三个关键因素"，每一层都配有他自己犯过的错误作为例证。

![职业花园模型：种子代表技能与兴趣，土壤代表上级、公司和团队，气候代表行业、地域与时机](/assets/career/day-day-up-playbook/chapter-9/01-infographic-career-garden-model.png)

### 种子——培育你自己的，而不是别人的

种子完全在你自己的掌控之中，只有当你"培育你真正应该长成的那个植物，而不是别人希望你长成的那个",它才会长得最快。他父亲希望他做医生；而他自己热爱乔叟，小时候上过电视做演讲，赢过全国性的商业案例大赛冠军。他的朝九晚五教会了他执行力；而他的晚五点到早九点——多年的教练实践、令人尴尬的视频、笨拙的邮件简报——培育出了后来成就他事业的那些能力。他引用纳瓦尔的话："做那些对你来说像玩耍、对别人来说是工作的事情。"失去自己的种子是有代价的：他曾在 Wealthsimple 还只是一家十二人的初创公司时，忽略了其 CEO 想要一份内容营销样稿的请求，因为他当时想做的是"战略"；五年后，当这家公司成长为独角兽（如今市值一百亿美元），他才加入。审视性的问题是："我培育的，是属于我自己的种子，还是别人替我种下的那颗？"

### 土壤——你无法靠加倍努力去弥补糟糕的土壤

有两个关于土壤的错误。第一，把选择权交给别人：被一家大牌公司挖角"感觉非常好"，但他违背自己的直觉加入了那家公司，发现那里的土壤又干又慢、充满政治、没有成长空间，而他因为把离开等同于失败，所以留得太久了。第二，没能识别出好的土壤：2016年，他放弃了 Shopify 一个企业客户经理的职位，当时股价只有 3 美元每股（"已经上市了，涨不了多少"），几年后又以每股 200 美元的价格加入。"如果你自己的眼光不够好，你根本看不出好的土壤"——所以要借用一位已经走在前面的导师或教练的眼光，而不是父母或朋友——他们"根本不知道自己在说什么"。审视性的问题是："问题是出在我自己身上，还是我周围的土壤，正在扼杀我的成长？"

> 🗣 **教练原话：** "好的土壤，能让最平庸的种子也长得旺盛；糟糕的土壤，能杀死最优秀的种子。你无法靠加倍努力去弥补糟糕的土壤。"

### 气候——最被低估的一层

一个蓬勃发展的气候就是火箭燃料（2010年代的科技行业；如今的 AI 浪潮）；一个正在萎缩的气候，则会让你感觉自己在爬坡。势头的信号包括：职位空缺在增加、更多公司在投入、相关技能的需求在上升。"上升的气候能让你显得幸运，而衰退的气候则会让你显得懒惰。"他在科技行业的黄金年代加入了一家 C 轮初创公司，起薪约五万美元，此后经历了 Google、Uber、Shopify，薪资在二十多岁到三十多岁之间涨了五倍——"说实话，我只是运气好，我正好处在对的气候里"。审视性的问题是："我所在的行业，正在向上走，还是正在被落下？"

### 方法：花园审视

1. 针对三个问题（种子/土壤/气候）分别写一段话作答。
2. 任何人告诉你你的种子、土壤或气候"应该"是什么样的——"朝相反的方向跑"。
3. **每次只调整一层。**
4. 关于土壤，借用他人的眼光：找一个比你早五年以上的人，请他们评估你目前的公司是不是好的土壤，并把他们的判断和你自己的判断做对比。

### 常见错误

- 因为品牌光环，或因为被挖角这件事本身带来的虚荣感，而选择土壤。
- 因为离开感觉像失败，而一直留在糟糕的土壤里。
- 用自己不够好的眼光去判断一家公司的未来（"已经上市了，涨不了多少"），而不是借助导师的判断。
- 完全忽视气候这个因素，然后在一个正在萎缩的行业里，反过来责怪自己不够快。

## 9.6 设定属于你自己的节奏：KPI 阶梯、两年法则，以及"配得上"的迷思

### 概念

"感觉停滞不前，并不代表你失败了，它意味着你的 KPI 已经变了。"曾经让你获得晋升的那些优势，会开始反过来成为你的阻力，因为每一个层级衡量的东西都不一样——而且没有人会告诉你这一点。

### KPI 阶梯

| 层级 | KPI | 具体表现 | 教练提到的策略 |
|---|---|---|---|
| 初级个人贡献者 | **可靠性** | 你的老板"把工作交给你时，会比交给其他同事更放心" | 周五截止，周四就交；不等被问就主动更新进度（"草稿已经完成 80%，明天照常能交"）；工作时间内，对时效性要求高的请求，一小时内回复——"最好的能力，就是随时能被找到" |
| 高级个人贡献者 | **主人翁精神** | 识别问题、界定范围、制定计划、在极少指导下执行；"为你的老板吸收复杂性" | 在开始前，用一句话定义什么叫"成功"；"如果这周我只有五个小时，我会做什么？"——"经理提拔的是能搬动大石头的人，不是那些把小石头搬得完美无缺的人"；有策略地学会说"不" |
| 团队经理 | **团队绩效** | "你不在的时候，你的团队能交付出什么" | 从系统层面解决反复出现的问题（标准流程、工作流重构、培训），而不是靠个人英雄式救火；委派的是结果，而不是任务；有意识地让自己"变得不再必要"——"如果你没法请一周假而不引发混乱，说明你还没有真正转型" |
| 总监 | **组织绩效** | 发展的是团队和组织，而不是个人 | — |

对华人专业人士来说，陷阱往往出现在高级个人贡献者这个阶段。"你在这件具体的事情上真的很厉害"听起来像是一句赞美，实际上意味着你已经卡住了；常见的反应是加倍钻研专业技能和可靠性。但"每个人都很可靠，经理真正在找的是杠杆"。这正是为什么能力更弱的人反而能当上经理：他们只是"在此刻真正重要的那个维度上，并没有更弱"。教练自己的教训是：作为第一次带十几人团队的新经理，他仍然停留在个人贡献者模式，休假期间还在工作，最后才意识到："我自己就是瓶颈";一位一直在争取更多授权的下属，一旦真正获得空间，就"表现惊艳"。要在拿到头衔之前就展现出经理级别的能力：从团队层面思考、把问题当作系统来处理、解决根本原因——比如搭建月末标准流程，让团队不再手忙脚乱，或者培训团队成员。在没有正式权力的情况下做辅导和引领，是你"隐形的晋升";当年身边每个经理都比他年长五岁以上时，教练依然积极主动地去指导别人；他之所以觉得自己已经准备好带第一位直接下属，是因为"早在正式拿到这个职位之前，我早就已经在做这份工作了"。

> 🗣 **教练原话：** "决定你想要的，到底是继续证明你曾经是谁，还是开始成为你需要成为的那个人。"

### 两年法则：公司提拔你，是因为他们需要你，而不是因为你配得上

那种认为"努力工作加上一个喜欢你的老板，就能换来晋升"的信念，是"一个谎言"：同事们辛苦耕耘了三到十年，眼睁睁看着公司从外部招人来担任那个职位。那些快速成长的人，选择向外寻求晋升。在外部，你才是叙事的掌控者——不管你的老板是不是觉得你表现平平，也不管公司说要再等三年，只要你能让面试官相信你具备这些能力，这次晋升就是你的。结果是：十年内五次升职，三十岁做到总监，"不是因为我是什么天才……而是因为我从来不让任何一家公司来替我决定自己的节奏"。只有当他手握一份外部 offer 时，经理们才会主动提出晋升："必须先有另一家公司发现你的价值，你自己的公司才会突然'意识到'。"

> 经理："John，我们能做点什么让你留下来吗？"
> 教练："也许，可以给我那个我一直在申请的晋升。"

方法：每两年，为下一个级别的职位去做一次外部面试，让你的雇主和市场竞争。"永远不要等待别人批准你成长。"等待你的老板主动给你一个团队，"可能意味着永远等下去；那就直接去面试那个职位。"

### 三条辅助规则

- **要么在学习，要么在赚钱，否则就该离开。**"永远处在学习或者赚钱的状态里。如果两者都不是，你就应该离开。"工作上的成功，属于朝九晚五；职业上的成功，属于晚五点到早九点。
- **头衔是唯一带不走的东西。**在条件相近的公司之间，教练承认自己"基本上是在追逐头衔"，或许这样做有点短视。工作生活的平衡，可能因为公司陷入困境而瞬间消失；一位深受喜爱的经理和团队，也可能因为组织重组而被硬生生拆散——"这种事在我身上发生过"。"一旦它写进你的简历，它就永远留在你的简历里"，而意义和有趣的工作，"往往是伴随着头衔一起来的"。
- **看重政治与产出，而不是努力本身。**从主持绩效评估的经验来看：真正被计入的，只有那些能影响业务的产出；那个五点准时下班的同事会问："这件事对业务是怎么赚钱的？我的工作和它是怎么连接的？"软技能能放大硬技能——一位九成时间都在管人的总监，会更愿意选择那个清晰、善于协作的工程师，而不是那个聪明却无法把话说明白的工程师。而且"你必须懂政治才能成功"，这里的政治指的是"关于影响力、关系和沟通如何运作的那些不成文规则"。教练自己的副业项目之所以被叫停，就是因为他没有赞助人，也没有把项目和业务目标挂钩。你所需要的那种机会，来自三种关系——赞助人（带来机会）、信息提供者（带来信息）、被辅导的人（带来声誉）——而且"赞助人找的不是有才华的人，而是能被看见的人"。因此，要"做事，同时也要让人知道"："看不见的影响力，和没有影响力没有区别。"

### 常见错误

- 卡住的时候，反而在原来那个层级的 KPI 上加倍投入。
- 让一家公司来设定你的节奏；一直等待内部认可，而那种认可往往只有在你拿到外部 offer 后才会出现。
- 把努力和绩效混为一谈——"努力工作让你走到了这里，但它不会带你走到下一步"。
- 在没有赞助人、也没有和业务目标挂钩的情况下，做自己的副业项目。
- 声誉走捷径的代价："建立需要二十年，毁掉只需要五分钟。"永远不要写下任何你不愿意登上华尔街日报头版的话；永远不要在背后说任何你不愿意当面说的话。

## 9.7 什么时候该离开，去往何方

### 概念："留下来这件事，正在对我做什么？"

客户 Angela 收到了经理毫不留情的反馈——"你甚至都没意识到自己的沟通有多糟糕，这几乎没法解释清楚"——她问了十个朋友，自己到底该不该辞职。八个人都说留下：市场不好、简历上会留下空档、"多少人求着想要你这份工作"。"他们每个人说的都没错……但同时，他们也大错特错。"

> 🗣 **教练原话：** "当别人给你建议时，他们其实不是在对你说话，他们是在对自己说话。"

朋友们看到的，是他们自己的工作、房贷和经理。教练自己因为听信这种逻辑而付出的代价是：他在一个入职第一周就知道不对的岗位上，硬生生留了一年（"一年，是……不引人怀疑的最低时限"）。在一次让他感到彻底隐形的会议之后，他问自己的经理："嘿，如果我离开这个岗位，你们真的会去补这个人吗？"——得到的却是含糊其辞的回答。公司其实根本不需要这个岗位。他的技能在退化，自信心在流失，花了整整两年才恢复；到了下一份工作，即便遇到一位很和善的经理，他依然因为残留的恐惧，为每一次一对一会议过度准备。

方法是一个重新框定，加上一个诊断：
1. 把"你会怎么做？"换成——**"留下来这件事，正在对我做什么？"**——在问任何人的意见之前，先诚实地从技能、自信和健康三个维度回答这个问题。
2. 向你的经理问那个"补岗"的问题。含糊其辞，本身就是答案。
3. 教练并不声称自己知道 Angela 最终该做什么决定；真正重要的，是她已经在问对的问题。

### 职业倦怠："再升一次职"要付出的代价

教练在这个话题上最早的一个故事是：他曾经把自己和公司、头衔绑定在一起，每周工作八十个小时，还"告诉自己我很喜欢这样"。他没办法在和女友吃饭时真正在场，因为满脑子都在担心"一份愚蠢的 PPT"；她"慢慢变成了她曾经那个快乐的自己的影子"。两年里他体重增加了大约三十磅，通勤时也常常坐过站睡着。他给那些拼命努力、总是有求必应的人的警告是："再升一次职"这种想法，忽略了一个事实：一次住院、一次崩溃，或者一个人的离开，就足以让一切脱轨。他的解法是：他辞职去了一份"工作更少、说'好'更少、赚得却更多"的工作。结合 9.1 里那个"枪"的问题，这一课的重点不是"少工作"，而是审视这个节奏正在让你付出什么代价，以及这个节奏是不是你自己选的。对内向者来说，保护自己的精力是一种正当的策略：在连续的会议之后留出三十分钟空白，尽量推动异步沟通（"有没有一个 TLDR 版本，我们可以异步讨论，好保护大家的日程？"），并且主动公开自己内向的特质，而不是试图去"改正"它。

### 找到方向：技能 → 热情 → 匹配

"最糟糕的职业错误，就是把你最好的年华，浪费在成就别人的事业上。"教练在职业战略领域待了二十年，才回归到写作这件事——那是他童年的梦想，曾被父母否决过（"当作家赚不到钱"）。他的三镜头方法：

1. **技能——靠证据，不是靠猜测。**回顾五个真实的项目，只写下那些真正产生了实际成果的技能。
2. **性格——用大五人格，不是 MBTI。**针对每一项技能问自己："我的性格，是在帮助我，还是在阻碍我？"（高尽责性有助于项目管理；低宜人性会阻碍团队管理；高开放性有助于数据分析）。"技能告诉你，你已经擅长做什么；大五人格告诉你，你可以不断打磨、直到无可阻挡的，是什么。"
3. **热情——"美好时光日记"**（出自《你要如何衡量你的人生》[原文：*Designing Your Life*]）：连续三周记录每一项活动带来的投入感与能量感；对那些让你精神振奋的时刻，标注 AEIOU——活动（Activities）、环境（Environments）、互动（Interactions）、物品（Objects）、人物（Users）。"那些你觉得'应该'喜欢的事，往往在消耗你；那些你偷偷喜欢的事，每次都在给你充电。"
4. **匹配**——把你的技能和热情输入给 AI，让它输出五个职位方向，附带描述、薪资、晋升路径，以及为什么匹配的理由。

> 🗣 **教练原话：** "我们其实有两次人生，第二次，是从我们意识到自己只有一次人生的那一刻开始的。"

### 迈出这一步：一次只改变一个变量

想要跨入任何一个新角色或新行业：（1）只改变职位头衔*或者*行业，永远不要两个一起改，因为面试官需要看到清晰的相关性——教练一直保留"战略与运营"这个头衔，只是把自己从传统企业切换到了科技行业；（2）通过咖啡聊天和目标公司员工的领英资料，弄清楚谁真正适合这个方向；（3）用故事让自己看起来像理想候选人——简历条目按"问题 → 技能 → 成果"来写，再叠加"三个超级故事"，用细节去证明目标岗位所需要的技能。一位在银行业做高级数据科学家的人，正是用这个方法横向转型成了一位高级 AI 产品经理。而当真正的老师是市场，而不是某门课程时："别再往脑子里塞更多的学习，把简历填满才是正事"——哪怕是一轮失败的申请，也能揭示出市场真正想要什么、哪些差距是真实存在的。

### 常见错误

- 问"你会怎么做？"然后把所有答案平均一下。
- 在一个公司其实并不需要的岗位上，硬撑那"最低限度的一年"。
- 一直告诉自己你很享受那种每周八十小时的工作节奏。
- 靠猜测而不是从真实项目里去读出你的技能；用 MBTI 来做判断。
- 同时改变头衔和行业。
- 报一门新课，而不是直接去投递申请。

## 9.8 AI 与你的职业生涯：一场发现自己的竞赛

### 概念

教练看到两类被恐惧驱动、同样陷入停滞的人：一类是"恐慌式学习者"，为了一些根本不相关的岗位，不停地囤积 AI 训练营和证书；一类是坚决要求禁止 AI 的"仇恨者"——"一个陷在焦虑里，一个陷在否认里。"AI 真正带来的伤害，是"你作为一个人的价值感"。让职业生涯"抗 AI 化"，重点不在于学更多 AI，而在于把 AI 当作工具，更深地投入到你身上那些独属于人类的价值里。

### 教练的推理——他自己失败的 AI 产品

他曾推出一款基于自己方法论训练的 AI 教练产品，定价只有他本人咨询费用的一小部分，结果失败了。客户一直在问："我能有多少时间跟你本人直接交流？"他的结论是："AI 已经把常识性的知识变成了大宗商品";客户真正愿意付钱买的，是真实的人生经验，以及能读懂"一个房间里那些没被说出口的东西"的能力。他用工业革命做类比：真正在那个时代获益的，不只是工程师，还有那些理解"工厂到底让什么成为可能"、并加倍投入自己原本就擅长的事情的管理者和销售人员。

> 🗣 **教练原话：** "这场竞赛，从来都不是关于发现 AI，它一直都是关于发现你自己。"

这和疫情期间那个"打磨你的尖峰"的故事是同一套逻辑：2020年，他在 Uber 刚新婚、背负房贷，硬着头皮上了一门他很讨厌的 Python 课程，直到他意识到自己想要的根本不是当一名数据科学家——他想要的是一份有安全感的工作。求职过程让他明白，他永远不可能在写代码上超过他的妻子（一位资深数据科学家），但没人能像他那样讲故事：他在案例面试中的成功率是百分之百。"别再试图去补齐你所有的短板，去打磨你的尖峰。"他转向了战略与运营领导岗位，并在 Uber 宣布大规模裁员的当天递交了辞呈。

### AI 正在如何改变这架阶梯

- **汇报正在变成大宗商品。**到了2026年，AI 写查询、做整合、出可视化，"比你煮咖啡的速度还快";它做不到的，是做出好的决策——而且你爬得越高，这一点就越明显。这正是为什么"承诺"（见9.4）会变得越来越珍贵。
- **任务层面使用 AI，已经是最基本的门槛。**"到了2026年，没人应该还在谈论任务层面的问题了"——智能体能在几秒钟内串联起一系列任务，"你的角色会被压缩成一个按按钮的人"。要往上走到流程层面的问题（扩大你的影响力，让更多人能解决更多问题——作为经理，他会问："这个活儿干得不错，那你打算怎么把这个影响力规模化？"），再往上走到业务层面的问题（用 AI 做出更好的、能创造机会的决策）。领导者并不是更聪明，他们只是"积累了更多的背景信息"，而 AI 能帮你更快地追上这些背景。"别再罗列你的 AI 工具箱了，开始展示你的业务影响力。"
- **判断力，才是真正的区分点。**教练用 AI 的决策规则是："如果这件事出了问题，会有多糟糕？"低风险的事情（会议纪要、市场调研、幻灯片大纲）→ 自动驾驶，交给 AI 并监督；"如果你现在还在手动做这些事，你已经落后了。"高风险的事情（一场棘手的干系人对话、一场需要说服领导层信任你判断的演讲、一次工作面试）→ 副驾驶模式，"永远不要把思考本身外包出去"。
- **匹配度依然重要。**"你是怎么用 AI 的？"本身就是一道匹配度测试题："从不用"显得僵化，"什么都用"显得没脑子。去搜一下"[公司名] 对 AI 的立场"，调整好你回答的语气，再补充一个具体的行业例子。

### AI 与真实性

AI 写出来的英文，除了你自己以外，谁都能一眼看出来——教练自己就看不出一位中国旅行社客服消息里的 AI 味，但他妻子一眼就注意到了、并感到尴尬；反过来，同样的情况也会发生在用 AI 写英文的华人专业人士身上。用 AI 来撰写内容，是"在表演能力，而不是真正建立能力"，而且"你所缺乏的那项能力，恰恰就是评判 AI 输出内容所需要的那项能力"。"表演者，会一直保持完美的打磨、也一直完全隐形……而真正的建设者，会有几个月听起来像个英语非母语者，之后就会听起来像一个领导者。"规则是：先自己决定要传达的信息（"如果你没法把核心信息浓缩成一句话，那你其实根本没有核心信息"），用你自己的英语写下来，带着错误也没关系——"我觉得我们应该推迟发布，数据还没准备好，我们周四能聊聊吗？"——然后只让 AI 来修正语法。面试准备也是同一个道理：所有人都用 GPT，听起来都差不多；用 AI 来拆解职位描述、找出你的能力点，然后用你自己的判断去做选择——"做一半机器，一半人，然后百分之百让人忘不了。"

### 方法：支点审视

1. 承认 AI 的存在；停止为你根本不想要的岗位而恐慌式学习。
2. 列出三件客户或同事看重你、而一个知识库无法替代的事情（真实的人生经验、读懂现场氛围的能力、讲故事的能力、判断力）。
3. 针对每一件，写出一种 AI 可以帮你腾出时间、去做更多这类事情的方式。
4. 把你使用 AI 的方式，重新表述到流程层面或业务层面，而不是任务层面。
5. 构建"可迁移的价值"——一项全球都需求旺盛的技能——把它当作这个时代最聪明的风险。
6. 如果你现在就需要简历上有知名品牌的 AI 经验，去完成一个企业设计的模拟项目（Forage 平台上：BCG 的生成式 AI 金融聊天机器人项目、Tata 的生成式 AI 数据分析项目）——"你不可能永远处在被雇用的状态，但你可以永远保持在拼搏的状态。"

### 常见错误

- 为一个你根本不想要的岗位囤积 AI 证书（焦虑），或者干脆拒绝接触（否认）。
- 在面试中罗列工具，而不是讲述解决过的问题。
- 让 AI 代写你的消息和自我介绍——"由 AI 制作"这件事，除了你自己，谁都能看出来。
- 试图补齐每一个短板，而不是去打磨你的那根尖峰。

## 练习集

### 练习

**练习1 — 忍耐力账本（9.1）。**写下你下一个职业目标。在它下面，列出它真实的三项代价（例如：政治博弈、自我推销、时间投入）。在每一项旁边写下"愿意"或"不愿意"——*真心的*，而不是"我好像不得不"。如果有任何一项是"不愿意"，写下你将有意识地承担的替代路径，并写一句你选择它时"不带怨恨"的话。

**练习2 — 应该 → 我怎样才能（9.1）。**写下你最常出现的三句"应该"句式。把每一句都转化为"我怎样才能……？"针对其中最重要的那一句，回答：我想要感受到什么？什么能让我有这种感受？我实际能从哪里获得它？然后起草两条路径（内部、外部）。

**练习3 — 重建链条（9.2）。**针对一种职场行为（例如：会议中的沉默），写下你目前的行动 → 习惯 → 性格 → 命运这条链条。然后写出重建后的链条，从最小的行动开始（"哪怕想法只是普通，我有想法就会说"）。坚持两周，把每一次实践都记录为证据。

**练习4 — 为失败而设计 + 账本审视（9.2）。**在你下一次演讲或面试之前，写下你希望收集到的那些具体批评；之后，记录你学到了什么、它排除了哪条路径。同一周内：回顾上周的日历和上个月的银行流水，写下它们"证明"了你是什么样的人，并选择一个行动来缩小这个身份和你所宣称的身份之间的差距。

**练习5 — 限时第三人称重写（9.3）。**五分钟。选择那件你最感到羞耻的职场经历。用你自己的名字，以第三人称把它写下来。挑选那些最能体现这个人贡献的事实。大声朗读三遍，把它保留作为你的面试版本。延伸练习：用完全相同的事实，把你的职业生涯自传写两遍——失败者版和英雄版——圈出你目前正在使用的那一版。

**练习6 — 聪明风险分类（9.4）。**列出你正在考虑的三个职业选择。针对每一个，写下最坏情况的损失和最好情况的收益。只保留那些下行空间小、有边界的选择。然后写下你最害怕的那一个风险，以及这个月你能采取的第一个具体行动。

**练习7 — 承诺句演练（9.4）。**拿一份你原本只会单纯汇报的分析结果。在后面加上："我看到的是___。如果由我来做决定，我会___，因为___。"大声说出来，直到它听起来真的像你自己的话；在你下一次汇报中用上它。

**练习8 — 花园审视（9.5）。**分别写一段话：我培育的，是属于我自己的种子，还是别人替我种下的那颗？问题是出在我自己身上，还是土壤正在扼杀我的成长？我所在的行业，正在向上走，还是正在被落下？确定你这个季度将要调整的那一层，并请一位领先你五年以上的人，来给你目前的土壤打个分。

**练习9 — KPI 自我定位（9.6）。**判断你目前所处的层级，用一句话写出它的 KPI。列出三件你正在做、却属于*上一个*层级 KPI 的事情。选出一个下一层级的行动（比如提前到周四交付、用一句话定义成功、把一项重复性任务正式交接出去），本周就去做。

**练习10 — 市场检查（9.6）。**写下你上一次外部面试的日期。如果已经超过两年，本月就为下一个层级的职位预约三次探索性交流。给自己目前的岗位打分：学习（1–5分）、赚钱（1–5分）；如果两项都低于3分，写下退出计划的第一步。

**练习11 — "留下来这件事，正在对我做什么？"（9.7）。**在问任何人之前，用一页纸写下：留在目前这个岗位，正在对你的技能、你的自信、你的健康做什么。然后和搭档做一次角色扮演，让对方扮演你的经理：*你：*"如果我离开这个岗位，你们真的会去补这个人吗？"*经理（搭档即兴给出一个含糊的回答）：*"这个嘛，我们得看看情况……"留意这种含糊其辞给你带来的感受。

**练习12 — 支点审视（9.8）。**写出三件同事看重你、而一个知识库无法替代的事情，针对每一件写出一种 AI 能帮你腾出时间去做更多这类事情的方式，以及一个 AI 用法，分别在任务、流程、业务三个层面重新表述——只保留你能真实支撑得起的那个最高层级。

### 模板

**应该 → 我怎样才能**
```
抱怨：       "___________ 应该 ___________。"
重写：       "我怎样才能 ___________？"
感受：       我想要感受到 ___________。
产生它：     ___________ 会让我有这种感受。
来源：       我实际能从 ___________（内部路径）／___________（外部路径）获得它。
```


**身份链条（重建版）**
```
行动：   即使 ___________，我依然会 ___________。
习惯：   我逐渐习惯了 ___________。
性格：   我是一个 ___________ 的人。
命运：   我在职场的任何地方都会 ___________。
```


**第三人称重新框定**
```
[你的名字]被要求去做 ___________，而没有其他人能做到这件事。
[你的名字]没有 ___________ 方面的背景，所以[他/她]自学了 ___________。
[他/她]从零到一做出了 ___________。
出错的那个 ___________，之所以出错，是因为 ___________（一个系统性的事实，而不是个人的问题）。
最终结果证明了 ___________，并促成了 ___________。
[你的名字]并没有在 ___________ 这件事上失败。[他/她]正是 ___________ 存在的原因。
```


**承诺句**
```
我看到的是 [某个洞察]。如果由我来做决定，我会 [某个决策]，因为 [某个理由]。
```


**聪明风险测试**
```
方案：___________
最坏情况（下行空间）：___________   → 有边界吗？是 / 否
最好情况（上行空间）：___________   → 无上限吗？是 / 否
判定：聪明的风险 / 愚蠢的风险
```


**挽留对话**
```
经理："我们能做点什么让你留下来吗？"
你：   "也许，可以给我那个我一直在申请的 ___________。"
```


**委派结果（经理的 KPI）**
```
我信任你来负责 ___________。成功的样子是 ___________。截止日期是 ___________。
我们一起把它规划出来，我会信任你自己去想清楚该怎样把它真正落地。
```


**AI 风险等级判断话术**
```
在决定是否让 AI 参与之前，我会先问自己一个问题：如果这件事出了问题，会有多糟糕？
如果风险较低，我会交给 AI 处理并加以监督——比如，___________。
如果风险较高，我只在必要的地方借助 AI，绝不把思考本身外包出去——比如，___________。
```


**用你自己的英语写消息（AI只负责改语法）**
```
我认为我们应该 ___________。___________（一句话理由）。我们能 ___________（请求）吗？
```

## 速记卡

**框架**
- 忍耐力测试：不是"我想要什么？"，而是"我愿意为此忍受什么？"→ 无论哪条路，都要拥有这个选择
- 枪的问题："这把枪，握在他们手里，还是握在我自己手里？"
- 应该 → "我怎样才能……？" → 想要的感受 / 什么能带来它 / 从哪里获得 → 两条路径
- 用证据战胜情绪：先决定身份认同 → 带着恐惧做最小的行动 → 收集证据 → 不行动比行动更痛苦
- 行动 → 习惯 → 性格 → 命运
- 为失败而设计：演讲 = 收集批评；面试 = 换来一次精准的拒绝
- 你的账本从不撒谎：日历 + 银行流水 = 你是谁
- 第三人称重写：羞耻的故事 → 第三人称 → 挑选体现贡献的事实 → 反复讲述
- 挫折 = 数据，不是身份
- 财富 = 伸展 × 坚持
- 控制视角 + 控制反应；聪明的风险 = 下行有边界，上行无上限
- 汇报 → 建议 → 承诺
- 冲突：战斗 / 逃跑 / 忽略（或冻结）——"事后我会为自己感到骄傲吗？"
- 花园：种子 / 土壤 / 气候——每次只调整一层
- KPI 阶梯：可靠性 → 主人翁精神 → 团队绩效 → 组织绩效
- 两年法则：回到市场；让你的雇主参与竞争
- 学习 / 赚钱 / 离开
- "留下来这件事，正在对我做什么？" + 补岗问题
- 方向：技能（来自真实项目） → 大五人格匹配 → 美好时光日记（AEIOU） → AI 匹配的职位
- 转型：一次只改变一个变量；弄清楚谁适合；三个超级故事
- AI：风险等级测试（自动驾驶 / 副驾驶）；任务 → 流程 → 业务；用你自己的英语，AI 只负责改语法

**值得记住的话**
- "想要是廉价的。""这是你自己选的，承担它。"
- "去他的，我就是要带着恐惧去做。"
- "是谁说我需要更多？"
- "两个故事都是真的，那就告诉自己那个更好的版本。"
- "永远不要让稀缺感来定你的价格。"
- "你无法靠加倍努力去弥补糟糕的土壤。"
- "永远不要等待别人批准你成长。"
- "如果你无可替代，你反而无法被提拔。"
- "别再往脑子里塞更多的学习，把简历填满才是正事。"
- "这场竞赛，从来都不是关于发现 AI，它一直都是关于发现你自己。"

**该做 / 不该做**
| 该做 | 不该做 |
|---|---|
| 问自己愿意忍受什么；无论哪种答案都拥有它 | 既想要回报，又对代价心生怨恨 |
| 带着恐惧行动，记录证据 | 等到"感觉准备好了"；依赖自我肯定 |
| 想法普通也要说出来 | 只有"值得说"的时候才开口 |
| 用第三人称把挫折重讲成数据 | 用被裁员的经历作为自我介绍的开场 |
| 承担下行有边界的风险；为自己的决定负责 | 靠赌博挽回损失；一直停留在汇报层面 |
| 借用导师的眼光看土壤；关注气候 | 因为品牌选土壤；在衰退的气候里责怪自己 |
| 展现下一层级的 KPI；每两年面试一次 | 在旧的 KPI 上加倍投入；等待内部认可 |
| 问"留下来这件事正在对我做什么？" | 问朋友"你会怎么做？" |
| 打磨自己的尖峰；用 AI 放大你的人类价值 | 恐慌式学习 AI；让 AI 代写你的声音 |
