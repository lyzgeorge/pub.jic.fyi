# 每天向上职场指南实战 — 原版全文

### 一本可用于练习的讲义式教材

*编译于 2026-09-23，基于 270 个转录视频（YouTube @MrJonathanCareer、B站与小红书频道；约 188,000 字的口述内容）。本书中的每一条陈述均来自这些转录内容；未添加任何语料之外的信息。*

## 使用方法

1. **把每一章当作一堂课来读。** 每个编号小节都遵循「概念 → 教练的推理（通常是面试官或经理的视角） → 分步方法 → 视频中引用的实战脚本 → 教练提醒的常见错误」的结构展开。
2. **先完成练习，再进入下一节。** 练习是用来「做」的，不是用来「读」的：把答案写下来，录下自己的回答，找朋友做角色扮演，重写「修改前 / 修改后」的版本。填空模板就是教练给出的脚本，只需填入你自己的信息。
3. **用速记卡做复习。** 每章结尾都有一页纸的框架、公式与常用表达总结——可以在面试或一对一沟通前一晚打印出来复习。
4. **求职阶段建议阅读顺序：** 第一章 → 第二章 → 第三章 → 第四章 → 第五章。**入职后：** 第六章 → 第七章 → 第八章，第九章贯穿始终。

如果两个视频的建议出现分歧（教练的建议在 2018 至 2026 年间也在演进），正文会说明这一点。

**想先看精简版？** 参见[精简版](../index.md)，内容更凝练、更侧重行动。
