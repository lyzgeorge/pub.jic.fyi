# pub.jic.fyi

一个收集实用背景、参考资料与审慎整理笔记的公开知识站。

**JIC** 是 **just in case**（以备不时之需），**FYI** 是 **for your information**（供你参考）。`pub.jic.fyi` 是一个为值得留存的信息准备的小型公开档案。

## 来源说明

本站是知识笔记站，并非权威机构。涉及学校、政府、雇主、医疗、移民、法律、金融或其他时效性事项时，请在行动前核对原始来源。
