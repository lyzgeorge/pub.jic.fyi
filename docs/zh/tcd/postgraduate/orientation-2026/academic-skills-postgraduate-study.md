# 成功完成研究生学习所需的学术技能

> **原始标题：** Academic Skills PG
>
> **课程日期：** 2026年9月10日
>
> **来源：** [Panopto 录播](https://tcd.cloud.panopto.eu/Panopto/Pages/Embed.aspx?id=215e2ba7-4cbb-4f9f-b672-b4b700ec1ee4)

研究生学习离不开**自我调节学习**：主动规划、监控并评估自己的认知、情绪和行为过程。需要管理的不只是学习方法，还包括动机、时间、学习环境与表现检查。

## 有意识地安排任务

先把不可变更的承诺写入日程，再为学习和真正的休息留出时间。将宽泛意图改成 SMART 目标：具体、可衡量、可实现、相关且有时限。任务清单可采用三种处理方式：极短任务立即完成，值得做的较长任务排入日程，不重要的任务直接舍弃。

优先级同时取决于重要性与紧迫性。重要且紧急的事马上处理；重要但尚不紧急的事提前计划；低重要性的打断不应挤占核心工作，低价值干扰则应删除。

![按重要性和紧迫性划分的四象限优先级矩阵](/assets/tcd/postgraduate/orientation-2026/academic-skills-postgraduate-study/priority-matrix.jpg)

矩阵强调：提前规划能保护“重要但不紧急”的工作。随后可用时间区块落实优先事项。录播介绍的番茄工作法是一种可选结构：专注25分钟、休息5分钟，完成四轮后安排更长休息。

## 用主动加工代替被动接触

学习没有唯一正确方式。有效方法要求主动加工信息，包括练习测试或问题、分散练习、阐释、联系已有知识、识别模式以及使用具体例子。讨论、想象、向他人讲解、提问、绘图、概念图和录制讲解，都会迫使学习者提取并重新组织知识。

尽早开始，才能把学习分散到多个时段。按任务选择合适空间并提前布置；没有固定书桌时，可准备便携学习箱来减少启动阻力。难以下笔时，先自由写作五分钟，梳理已知、未知和待查问题。

## 学术写作的五项要求

研究生学术写作应做到正式、清晰连贯、客观克制、以证据支撑，并体现批判与分析。

1. **正式：** 避免削弱准确性的缩写、陈词滥调和口语。
2. **清晰：** 全文与段落都要简洁、连贯、衔接自然、结构合乎逻辑。
3. **客观：** 用有证据的准确判断替代情绪化强化词。
4. **有证据：** 综合多位作者与本学科认可的证据，并用清楚的过渡说明来源之间的关系。
5. **批判分析：** 质疑假设、评估信息、识别偏见，并展示证据如何导向结论。

研究时要知道去哪里寻找可靠证据，例如学科数据库和学科馆员推荐的资源，并从一开始就记录来源。呈现他人观点可采用释义、摘要、引文和综合；引述动词应准确表达作者对该观点的态度和确信程度。

引用既能标明思想来源、避免抄袭，也能支撑论证、展示阅读范围并帮助读者找到原文。因此，引用属于推理过程，而不只是格式要求。

## 从描述走向评价

批判性思维要求问题超越“发生了什么”。Plymouth 模型依次推进描述、分析与评价：先确定什么、哪里、谁、何时；再追问为什么、如何发生以及有哪些替代可能；最后判断意义、影响、结论与下一步。

![Plymouth 批判性思维模型：从描述性问题逐步推进到分析和评价](/assets/tcd/postgraduate/orientation-2026/academic-skills-postgraduate-study/plymouth-critical-thinking-model.jpg)

模型的核心是把推理写出来。每个重要论点都应回答“这说明什么”：解释其重要性、各部分关系，以及证据能够支持的后续结论。

## 简明工作流程

- 安排固定承诺、学习时段与休息。
- 在任务变得紧急之前保护重要工作。
- 用提取、间隔、讲解和例子主动学习。
- 尽早开始写作，哪怕先完成一段探索性草稿。
- 用合适证据建立论点，并在研究时同步记录来源。
- 修改正式程度、清晰度、客观性、衔接和推理。
- 检查每个重要论点的意义与影响。
