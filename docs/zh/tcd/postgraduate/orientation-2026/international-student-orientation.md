## 国际学生支持

### Trinity Global Room

**Trinity Global Room** 是 TCD 面向国际学生的支持与社区中心。40 多名国际及爱尔兰学生大使提供同伴建议、服务转介和社交支持。学期内开放时间为周一至周五 09:00–21:00。

Global Room 位于 Watts Building 一楼，紧邻 Academic Registry。

![校园地图：Trinity Global Room 位于 College Park 东侧的 Watts Building 附近。](/tcd/postgraduate/orientation-2026/assets/international-student-orientation/global-room-map.jpg)

*Global Room 标注在 Watts Building 附近，靠近 Westland Row 和 Academic Registry。*

Global Room 还举办移民咨询、迎新活动和文化活动。联系邮箱为 `tcdglobalroom@tcd.ie`；近期活动和咨询时间发布于 `@tcdglobalroom`。

## 移民登记

非欧盟、欧洲经济区、英国或瑞士公民通常需要在入境许可到期前向 Immigration Service Delivery（ISD）登记，一般应在抵达后 90 天内完成。

### Stamp 2 与 Stamp 2A

| 许可 | 常见适用类别 | 工作权限 |
| --- | --- | --- |
| **Stamp 2** | 全日制学位学生，包括全日制硕士生 | 学期内每周最多 20 小时，指定假期内每周最多 40 小时；以现行规定为准 |
| **Stamp 2A** | 只就读一个学期的交换生或访问学生 | 不具备讲座所述的 Stamp 2 工作权限 |

一年制全日制硕士仍属于全日制学位，不属于单学期交换类别。

### 登记流程

1. 通过 ISD portal 预约，日期必须晚于课程正式开始日期。身份验证可能使用 ID-Pal。
2. 在预约前一周内生成注册证明。
3. 携带所需材料前往 Burgh Quay Registration Office。
4. 使用实体借记卡或信用卡支付讲座所述的 €300 费用；不接受现金或非接触式支付。

### 所需材料

| 材料 | 说明 |
| --- | --- |
| 有效护照 | 证明身份及入境许可 |
| 注册证明 | 在 `my.tcd.ie` 中进入 **Registration → Confirmation of Registration** 生成，并从 portal intray 下载 |
| 学费支付证明 | 通常包含在 Trinity 注册证明中 |
| 资金证明 | 免签证国家学生可能需要提供；金额取决于课程长度和当前 ISD 规定 |
| 私人医疗保险 | 须覆盖居留期间并符合 ISD 要求 |
| 实体银行卡 | 用于支付登记费 |

### Irish Residence Permit

**Irish Residence Permit（IRP）**记录许可类型和到期日期，并寄送至预约时确认的地址。若 15 个工作日内仍未收到，应通过 ISD customer-service portal 查询。

工作权限随对应移民许可到期而结束，应直接核对 IRP 上的日期。

## 离开爱尔兰旅行

爱尔兰居留许可不会自动赋予进入其他国家的权利。

- **申根区：** 爱尔兰不属于申根区，前往申根国家可能需要单独申请签证。
- **英国和北爱尔兰：** IRP 本身不能作为入境许可；是否需要签证或 Electronic Travel Authorisation 取决于国籍和出行目的。
- **申请材料：** 各国使馆自行规定材料，预约名额也可能有限。

## 银行、工作与公共服务

| 系统 | 用途 |
| --- | --- |
| 爱尔兰银行账户 | 接收工资及处理本地付款；移民登记本身不要求开户 |
| PPS number | 用于就业、税务、社会福利及部分公共服务的个人识别号码 |

银行开户要求各不相同。常见材料包括护照、爱尔兰地址证明、学生身份证明，以及部分银行要求的 IRP 或原居住国银行流水。

申请 **Personal Public Service number（PPSN）** 时，先创建 MyGovID，再通过 MyWelfare 提交。常见材料包括身份证明、爱尔兰地址和申请理由；当前 Trinity 注册证明可用于支持学生身份和地址信息。

## 医疗保险

非欧盟学生须持有符合移民规定的私人医疗保险。保险应覆盖整个居留期，并包括急诊治疗和住院保障。

讲座提到的供应商包括 Irish Life Health、VHI、Laya Healthcare 和 Study & Protect。第一年学生也可使用原居住国保险，但必须符合 ISD 要求。

## 安全与诈骗

### SafeZone

**SafeZone** 是 Trinity 的校园安全应用。触发警报时，它可以向校园保安共享用户位置，并提供急救、非紧急协助和紧急求助入口。

### 应对诈骗

住宿、银行和移民类诈骗常通过制造紧迫感促使受害者立即行动。

1. 暂停交易或对话。
2. 独立核对网站域名及机构身份。
3. 自行查找官方联系方式，不使用可疑消息中提供的号码。
4. 不通过电话泄露密码、验证码或银行凭据。

## 文化适应

**Global dexterity** 指在保留个人价值观和身份的同时，根据不同文化情境调整行为的能力。

| 可见文化 | 不易察觉的文化 |
| --- | --- |
| 饮食、服装、音乐、庆祝活动和标识 | 沟通方式、分歧表达、权威关系、正式程度和学术规范 |

爱尔兰沟通有时较为间接。`That's interesting` 或 `I'll see what I can do` 可能用于缓和分歧或拒绝。如果口音或表达影响理解，尤其在学术交流中，应立即请对方重复、放慢或换一种说法。

## 实际行动顺序

| 阶段 | 行动 |
| --- | --- |
| 抵达后 | 更新 Trinity 系统中的爱尔兰地址，找到 Global Room，并配置 SafeZone |
| 移民登记前 | 确认许可类别，通过 ISD portal 预约并生成最新材料 |
| 登记后 | 核对 IRP 信息及寄送状态 |
| 工作前 | 确认 Stamp 2 工作权限，再准备合适的银行账户和 PPSN |
| 出境旅行前 | 单独核对目的地入境要求 |
| 学期内 | 尽早澄清不熟悉的表达，并建立学术与社交支持网络 |
