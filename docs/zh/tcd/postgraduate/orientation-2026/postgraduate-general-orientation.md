# 研究生综合迎新指南

> **原始标题：** PG General Orientation Monday
>
> **活动日期：** 2026 年 9 月 7 日
>
> **来源：** [Panopto 录像](https://tcd.cloud.panopto.eu/Panopto/Pages/Viewer.aspx?id=63000a95-73d6-4e3e-8898-b4b700e9440e)

这场迎新介绍了 Trinity College Dublin（TCD）研究生最常用的注册、学业、健康、校园和图书馆服务。

## 先办好注册和基本手续

开学后许多事务都依赖完整、准确的学生资料，建议先完成以下事项。

1. 通过 `my.tcd.ie` 注册、上传照片并领取 T Card。
2. 阅读并妥善保存课程手册或研究手册；课程规则、考核方式和重要节点通常都能在其中找到。
3. 联系校内部门时使用 TCD 邮箱，并附上八位数学生编号。
4. 如地址或电话号码发生变化，及时在 `my.tcd.ie` 更新。
5. 通过课程反馈、学生代表等正式或非正式渠道提出意见。

### 问题应咨询哪个部门

| 服务 | 职责范围 | 联系途径 |
| --- | --- | --- |
| **Postgraduate Advisory Service（PAS，研究生咨询服务）** | 保密的一线咨询、倡导、转介、技能工作坊、研究生支持小组及有限的紧急经济援助 | `postgrad.support@tcd.ie`、`@tcdpgadvisory` |
| **Academic Registry（学籍注册处）** | 申请、注册、学生记录、费用、学生证、考试、毕业及官方文件 | [ask.tcd.ie](https://ask.tcd.ie/) |
| **Dignity, Respect and Consent Service** | 披露与投诉、同意、性行为不端、霸凌和骚扰 | TCD dignity and respect service |
| **Equality, Diversity and Inclusion** | 包容、歧视、平等培训及相关资源 | TCD equality service |
| **Policies Hub（政策中心）** | 大学程序和政策，包括学生投诉、酒精和药物、心理健康及儿童保护 | TCD policies website |

Academic Registry 可开具在读证明和住址证明。一般需要两个工作日，业务繁忙时可能需要四个工作日。

## 做好学业规划

### 从截止日期倒排计划

研究生课程和研究项目往往有多个相互交错的截止日期，需要提前规划，而不是临近提交时才集中处理。

- 记录考核日期、里程碑、必需材料及行政截止日期。
- 从每个截止日期向前倒排，把任务拆成若干可完成的小步骤。
- 设定现实目标，并为研究、阅读、写作和修改预留时间。
- 向讲师或导师确认学术要求，而不是自行推断。
- 尽早确认自己需要参加哪些技能培训。

需要合理便利安排的学生应通过 `my.tcd.ie` 向 disAbility Service 登记。若希望第一学期考试时即可使用相关安排，最好在十月最后一个星期五前完成申请；之后仍可申请，但未必能赶上本学期的考试。

| 服务 | 功能 |

| **学科馆员** | 学科检索、数据库、阅读清单资料和研究指导 |
| **Student Learning Development** | 工作坊、在线资源、个别咨询、学术写作、论证构建及学习方法 |
| **Academic Writing Centre** | 对短篇写作样本提供反馈 |
| **Careers Advisory Service** | 职业规划、工作坊、招聘会、简历和面试诊所，以及 MyCareer 中的机会 |
| **disAbility Service** | 需求评估、辅助技术、学术支持和考试便利安排 |

## 身心健康也是学习保障

稳定的学习状态离不开运动、饮食、补水、睡眠和心理健康支持。身体不适、生病或需要精神与信仰支持时，也可以使用学校的相应服务。

| 服务 | 提供内容 |
| --- | --- |
| **College Health Centre** | 学生基础医疗服务，包括医生、护士、性健康门诊和优惠收费的物理治疗 |
| **Student Counselling Services** | 个别辅导、支持小组、工作坊、研究生支持小组和在线项目 |
| **Sports Centre** | 健身房、游泳池、攀岩墙、健身课程、社交运动和户外设施；学生用 T Card 开通使用权限 |
| **Chaplaincy** | 牧师、多种信仰社群的联系、祈祷空间，以及面向任何信仰或无信仰学生的支持 |

如在非办公时间需要倾诉或危机支持，可联系 `50808` 的 **Text About It**，也可使用学生运营的 **NiteLine**。

## 参与校园生活与学生代表事务

除了上课和做研究，研究生也可以通过学生代表、社团和校园活动建立联系、表达意见。

- **班级和学院代表** 向课程和学校传达研究生的意见。
- **TCD Students' Union（学生会）** 在法律上独立于大学，负责学生代表工作，并提供福利、学业支持和权益倡导；学生会也设有研究生事务官。
- **Global Room** 为国际学生提供移民信息、同伴支持和文化活动。
- **体育俱乐部** 涵盖约 50 项活动，接受从初学者到竞技水平的参与者。
- **学生社团** 覆盖学科、文化、身份、出版、艺术及其他兴趣领域。

刚开始可以选择一个与专业相关的社团、一项自己熟悉的活动，再尝试一项新活动。也可以向俱乐部或社团提议举办面向研究生的活动。

## 熟悉校园服务

### IT 访问

IT 迎新主要帮助学生完成以下事项：

1. 激活电脑账户和电子邮件；
2. 连接学生 Wi-Fi；
3. 访问课程资料；
4. 查找讲座和教室；
5. 获取受支持的软件；
6. 购买或配置合适的硬件；以及
7. 请求 IT 支持。

### T Card

**T Card** 既是学生证，也是进入部分楼宇、登录打印机和复印机、在校园内无现金付款的凭证。它还可用于申请校内外学生优惠。在校园餐饮点使用 T Card 付款可享九折。

### 餐饮和学生空间

校内餐饮选择包括 Buttery、Dining Hall、Forum、Perch、学生会咖啡厅和商店，以及 Pavilion。Dining Hall 和 Buttery 提供相同的食物但环境不同；多数餐饮点傍晚前关闭，Pavilion 则提供较晚时段的热食。

TCD 没有统一的学生中心，学生空间分布在校园各处。**Common Room** 和 **1937 Reading Room** 为研究生专属空间；其他地点服务于校园的不同区域。

![Trinity 主校区中研究生和一般学生空间的地图。](/assets/tcd/postgraduate/orientation-2026/postgraduate-general-orientation/student-spaces-map.jpg)

*研究生和一般学生空间分布于校园各处，而非集中在单一学生中心。*

### 交通与可持续发展

活动建议在都柏林步行、骑车和使用公共交通。TFI Live 应用提供路线和票价信息；Young Adult 和 Student Leap Card 则按年龄和学生身份提供公共交通折扣。

在校园内可以随手关闭闲置设备、使用饮水补给点和可重复使用的杯子、做好垃圾分类，并通过回收机退还符合押金返还条件的饮料容器。TCD 的可持续发展地图标出了回收点、饮水机、洗手间和可持续餐饮等设施。

## 安全

通过 **SafeZone** 可以直接联系 TCD Security，请求急救、安保或紧急协助。独自在校园工作时还可以使用签到功能；如果签到后一直没有签退，Security 会主动跟进。

| 联系方式 | 电话 |
| --- | --- |
| College Security | `01 896 1317` |
| 校园紧急电话 | `01 896 1999` |

校园内发生紧急情况时，应使用 SafeZone 或拨打校园紧急电话，由 TCD Security 协调救援人员进入校园。听到火警后应立即沿标示的疏散路线离开，不要留在原地等待确认。

## 研究生阶段的学习方式

### 建立同伴网络

研究生学习有时会让人感到孤立，尤其是在独立研究阶段。除了维系课程之外的人际关系，也要和同学保持联系；他们最了解相同的截止日期和学校环境。

### 像全职工作一样安排学习，也要留出休息时间

研究生学习的投入大致相当于一份全职工作。偶尔晚上加班在所难免，但不应成为常态。

- 建立一套可以长期坚持的日程。
- 避免安排过满，为阅读、研究和写作留出足够时间。
- 继续保留兴趣爱好、运动、社交和离开书桌休息的时间。
- 效率明显下降时先休息一会儿，再回来重新梳理问题。
- 学习中出现挫败感很正常，并不意味着这段学业已经失败。

### 理解爱尔兰学术文化

爱尔兰日常交流通常比较随意，但在学术场合仍要注意基本礼仪。

| 情境 | 活动中说明的惯例 |
| --- | --- |
| 走廊问候 | “How's it going?” 通常是问候语，而不是要求详细汇报近况 |
| 社交守时 | 非正式场合可能接受小幅迟到 |
| 学术守时 | 讲座和与教职员会面时准时或提前几分钟到达 |
| 学术称谓 | 在被邀请直呼名字前，使用 `Dr`、`Professor` 或相应称谓 |
| 非正式语言 | 爱尔兰及 Trinity 特有词汇可能与其他英语变体不同；不理解术语时应询问 |

## 使用图书馆

TCD Library 是法定送存研究图书馆，馆藏约 700 万件实体资料、130 万册电子书和 15 万种电子期刊，并提供超过 3,000 个学习座位。

### 空间与访问

- **1937 Reading Room** 是 24 小时开放的研究生学习空间，配有电脑室、交谈室、小厨房和储物柜。
- **Kinsella Hall** 是另一处对全体学生开放的 24 小时学习空间。
- Lecky、Ussher 和 Boland 图书馆的研究生专用书桌分配给博士生和研究型硕士生，而非授课型硕士生。
- 各图书馆还设有可预约的小组讨论室和感官友好学习空间。

### 借书与调阅馆藏

高等学位学生一次最多可借 50 本普通外借图书，借期为 12 周；如无人预约或召回，还可续借一次，再延长 12 周。

查找纸本图书时，可根据图书馆目录中的索书号定位。许多馆藏存放在书库而非开放书架，可通过目录中的 **Click and Collect** 申请调阅，并到指定服务台领取。开放书架上的资料通常会在 24 小时内备妥，书库资料一般可在下一个工作日领取。

### 电子书的区别

| 电子书类型 | 访问方式 |
| --- | --- |
| 图书馆常规购买的电子书 | 通常可以按图书馆的访问规则远程使用 |
| 英国电子法定送存电子书 | 受法定送存规定限制，只能在图书馆指定电脑上使用 |

每个学科都有学科馆员。Library HITS 课程涵盖图书馆基础、数据库、抄袭、引用、文献管理、文献综述、学术写作、批判性阅读及相关研究技能。

## 建议的办理顺序

| 阶段 | 行动 |
| --- | --- |
| 初始设置 | 注册、领取 T Card、阅读手册、更新联系方式，并激活 IT 和 Wi-Fi 访问 |
| 学术规划 | 记录截止日期、确认预期、会见学科馆员，并登记所需支持或便利安排 |
| 校园设置 | 找到研究生空间、安装 SafeZone，并了解 T Card、交通、餐饮和可持续系统 |
| 学期期间 | 根据问题联系 PAS 或 Academic Registry，保持规律且不过度透支的学习节奏，并与同学保持联系 |
| 研究和作业 | 使用馆藏调阅、学术数据库、学科馆员、Student Learning Development 和 Library HITS 培训 |
| 需要支持时 | 联系健康服务、心理辅导、PAS、学生会、Security 或其他专业服务，而不是等问题升级 |
