# 研究生综合迎新

> **原始标题：** PG General Orientation Monday
>
> **活动日期：** 2026 年 9 月 7 日
>
> **来源：** [Panopto 录像](https://tcd.cloud.panopto.eu/Panopto/Pages/Viewer.aspx?id=63000a95-73d6-4e3e-8898-b4b700e9440e)

本场活动梳理了 Trinity College Dublin（TCD）向研究生提供的行政、学术、福祉、校园及图书馆系统。

## 行政基础

在处理更复杂的问题前，先完成基本的行政设置。

1. 通过 `my.tcd.ie` 注册、上传照片并领取 T Card。
2. 阅读并保存课程手册或研究手册；它是了解课程规则、考核和里程碑的主要依据。
3. 联系校内部门时使用 TCD 邮箱，并附上八位数学生编号。
4. 在 `my.tcd.ie` 中保持爱尔兰地址和电话号码为最新状态。
5. 通过正式和非正式的反馈渠道说明哪些安排有效、哪些需要改进。

### 问题应咨询哪个部门

| 服务 | 职责范围 | 联系途径 |
| --- | --- | --- |
| **Postgraduate Advisory Service（PAS，研究生咨询服务）** | 保密的一线咨询、倡导、转介、技能工作坊、研究生支持小组及有限的紧急经济援助 | `postgrad.support@tcd.ie`、`@tcdpgadvisory` |
| **Academic Registry（学籍注册处）** | 申请、注册、学生记录、费用、学生证、考试、毕业及官方文件 | [ask.tcd.ie](https://ask.tcd.ie/) |
| **Dignity, Respect and Consent Service** | 披露与投诉、同意、性行为不端、霸凌和骚扰 | TCD dignity and respect service |
| **Equality, Diversity and Inclusion** | 包容、歧视、平等培训及相关资源 | TCD equality service |
| **Policies Hub（政策中心）** | 大学程序和政策，包括学生投诉、酒精和药物、心理健康及儿童保护 | TCD policies website |

Academic Registry 可开具在读证明和住址证明。活动说明，通常处理需两个工作日；繁忙期间可延长至四个工作日。

## 学术运作系统

### 从要求倒推规划

研究生学习需要比临近截止日期才处理任务更早地掌控期限和预期。

- 记录考核日期、里程碑、必需材料及行政截止日期。
- 由每项截止日期倒推，拆分为更小的交付成果。
- 设定现实目标，并为研究、阅读、写作和修改预留时间。
- 向讲师或导师确认学术要求，而不是自行推断。
- 尽早识别需要的技能培训。

需要合理便利安排的学生应通过 `my.tcd.ie` 向 disAbility Service 登记。活动指出，该服务的目标是在十月最后一个星期五前落实第一学期的考试便利安排；之后仍可申请，但可能无法及时实施。

### 学术支持服务

| 服务 | 功能 |
| --- | --- |
| **学科馆员** | 学科检索、数据库、阅读清单资料和研究指导 |
| **Student Learning Development** | 工作坊、在线资源、个别咨询、学术写作、论证构建及学习方法 |
| **Academic Writing Centre** | 对短篇写作样本提供反馈 |
| **Careers Advisory Service** | 职业规划、工作坊、招聘会、简历和面试诊所，以及 MyCareer 中的机会 |
| **disAbility Service** | 需求评估、辅助技术、学术支持和考试便利安排 |

## 将福祉视为学习基础设施

学业表现和福祉会相互影响。本场活动将运动、饮食、补水、睡眠、心理健康、灵性支持和患病时的照护视为可持续学习系统的一部分。

| 服务 | 提供内容 |
| --- | --- |
| **College Health Centre** | 面向学生的基础医疗，包括医生和护士服务、性健康诊所以及减费物理治疗 |
| **Student Counselling Services** | 个别辅导、支持小组、工作坊、研究生支持小组和在线项目 |
| **Sports Centre** | 健身房、游泳池、攀岩墙、健身课程、社交运动和户外设施；学生用 T Card 开通使用权限 |
| **Chaplaincy** | 牧师、多种信仰社群的联系、祈祷空间，以及面向任何信仰或无信仰学生的支持 |

对于非办公时间的倾听和危机支持，活动列出了 `50808` 的 **Text About It** 以及学生运营的 **NiteLine** 服务。

## 参与和代表机制

研究生参与不止发生在课堂和研究小组中。

- **班级和学院代表** 向课程和学校传达研究生的意见。
- **TCD Students' Union（学生会）** 在法律上独立于大学，提供代表、福祉和教育支持、倡议以及研究生事务官。
- **Global Room** 为国际学生提供移民信息、同伴支持和文化活动。
- **体育俱乐部** 涵盖约 50 项活动，接受从初学者到竞技水平的参与者。
- **学生社团** 覆盖学科、文化、身份、出版、艺术及其他兴趣领域。

一个实际的起点是：选择一个与本人学科相关的社团、一项熟悉的活动和一项新的活动。研究生也可通过提出面向本群体的活动，影响俱乐部和社团的安排。

## 校园系统

### IT 访问

IT 迎新的流程包括：

1. 激活电脑账户和电子邮件；
2. 连接学生 Wi-Fi；
3. 访问课程资料；
4. 查找讲座和教室；
5. 获取受支持的软件；
6. 购买或配置合适的硬件；以及
7. 请求 IT 支持。

### T Card

**T Card** 是学生身份证明、楼宇访问凭证、打印机和复印机登录卡及校园无现金支付卡。它也可用于申请校内外学生折扣。活动称，在校园餐饮点使用 T Card 支付可获九折优惠。

### 餐饮和学生空间

校内餐饮选择包括 Buttery、Dining Hall、Forum、Perch、学生会咖啡厅和商店，以及 Pavilion。Dining Hall 和 Buttery 提供相同的食物但环境不同；多数餐饮点傍晚前关闭，Pavilion 则提供较晚时段的热食。

TCD 没有一个统一的学生中心，而是提供由多个学生空间构成的网络。**Common Room** 和 **1937 Reading Room** 为研究生专属空间；其他地点服务于校园的不同区域。

![Trinity 主校区中研究生和一般学生空间的地图。](/assets/tcd/postgraduate/orientation-2026/postgraduate-general-orientation/student-spaces-map.jpg)

*研究生和一般学生空间分布于校园各处，而非集中在单一学生中心。*

### 交通与可持续发展

活动建议在都柏林步行、骑车和使用公共交通。TFI Live 应用提供路线和票价信息；Young Adult 和 Student Leap Card 则按年龄和学生身份提供公共交通折扣。

校园的可持续做法包括关闭未使用的设备、使用补水设施和可重复使用杯、分类回收，以及通过逆向自动售货机退回符合条件的容器。TCD 可持续发展地图标示了回收点、饮水机、洗手间和可持续餐饮等设施。

## 安全

**SafeZone** 可将用户直接连接至 TCD Security。它支持急救、安保协助、紧急情况以及在校园独自工作者的签到；用户签到后若未签退，Security 可以跟进。

| 联系方式 | 电话 |
| --- | --- |
| College Security | `01 896 1317` |
| 校园紧急电话 | `01 896 1999` |

发生校园紧急情况时，活动要求学生使用 SafeZone 或校园紧急号码，以便 TCD Security 为应急人员协调通行。应将火警当作真实事件处理：按标示的紧急路线离开，而不是等待确认。

## 研究生学习实践

### 建立同伴网络

研究生学习可能变得孤立，特别是独立研究期间。应维系课程内外的人际关系，包括理解相同截止日期和机构环境的同学。

### 将学习当作有边界的全职工作

活动将研究生学习定位为大体可与全职工作相比的事务。偶尔需要晚间工作，但不应成为常态。

- 安排可重复执行的日程。
- 在不作过度承诺的前提下，为学术工作保留足够时间。
- 保持兴趣爱好、运动、友谊和离开书桌的时间。
- 工作效率下降时短暂休息，再以更清晰的视角回到问题。
- 预期会有挫败阶段，但不要把它们视为课程失败的证据。

### 理解爱尔兰学术文化

爱尔兰的社交沟通常较为随意，但学术角色仍有相应的预期。

| 情境 | 活动中说明的惯例 |
| --- | --- |
| 走廊问候 | “How's it going?” 通常是问候语，而不是要求详细汇报近况 |
| 社交守时 | 非正式场合可能接受小幅迟到 |
| 学术守时 | 讲座和与教职员会面时准时或提前几分钟到达 |
| 学术称谓 | 在被邀请直呼名字前，使用 `Dr`、`Professor` 或相应称谓 |
| 非正式语言 | 爱尔兰及 Trinity 特有词汇可能与其他英语变体不同；不理解术语时应询问 |

## 图书馆系统

TCD Library 是法定送存研究图书馆，拥有约 700 万册实体资料、130 万册电子书、15 万种电子期刊和超过 3,000 个学习座位。

### 空间与访问

- **1937 Reading Room** 是 24 小时开放的研究生学习空间，配有电脑室、交谈室、小厨房和储物柜。
- **Kinsella Hall** 是另一处对全体学生开放的 24 小时学习空间。
- Lecky、Ussher 和 Boland 图书馆的研究生专用书桌分配给博士生和研究型硕士生，而非授课型硕士生。
- 可预约的小组房间和感官友好空间分布在图书馆系统内。

### 借阅与调取

活动说明，高等学位学生一次最多可借 50 本普通外借图书，期限为 12 周；在未被召回的情况下，还可续借一次 12 周。

使用图书馆目录中的索书号寻找纸本图书。大量馆藏在库而非开放书架上，目录的 **Click and Collect** 功能可将资料送至合适的服务台。架上资料通常 24 小时内可取，库房资料通常在下一工作日可取。

### 电子书的区别

| 电子书类型 | 访问方式 |
| --- | --- |
| 常规采购电子书 | 按图书馆通常访问条件远程使用 |
| 英国电子法定送存电子书 | 因法定送存限制，只能在指定图书馆电脑上使用 |

每个学科都有学科馆员。Library HITS 课程涵盖图书馆基础、数据库、抄袭、引用、文献管理、文献综述、学术写作、批判性阅读及相关研究技能。

## 实用顺序

| 阶段 | 行动 |
| --- | --- |
| 初始设置 | 注册、领取 T Card、阅读手册、更新联系方式，并激活 IT 和 Wi-Fi 访问 |
| 学术规划 | 记录截止日期、确认预期、会见学科馆员，并登记所需支持或便利安排 |
| 校园设置 | 找到研究生空间、安装 SafeZone，并了解 T Card、交通、餐饮和可持续系统 |
| 学期期间 | 根据问题使用 PAS 或 Academic Registry，保持有边界的学习日程，并持续与同伴联系 |
| 研究和作业 | 使用目录调取、数据库、学科馆员、Student Learning Development 及 Library HITS 培训 |
| 需要支持时 | 联系健康服务、心理辅导、PAS、学生会、Security 或其他专业服务，而不是等问题升级 |
